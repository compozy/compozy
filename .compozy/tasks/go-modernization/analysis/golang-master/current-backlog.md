# Current Go Modernization Backlog

## Purpose and status vocabulary

This is the execution reference for the Go audit restarted on 2026-08-01 after the `golang-master` update. It reconciles the eight fresh slice reports with the current working tree. It does not replace the source evidence in those reports, and it does not claim completion while implementation waves are still mutating the tree.

Statuses mean:

- **Verified:** implemented, reviewed against the restarted doctrine, and covered by focused evidence. A final source-frozen gate is still required.
- **Active:** an owner is implementing the finding now. The implementation is not accepted until focused tests and adversarial review pass.
- **Partial:** a valid part is implemented, but the finding's full invariant remains open.
- **Open:** confirmed and not yet implemented.
- **Decision:** confirmed architecture or product decision required before implementation.
- **Rejected:** the suggested change was disproved or is semantically inapplicable. The evidence remains part of the audit.

## Coverage snapshot and refresh obligation

The immutable restart baseline is 147 buildable packages and 5,097 Go files across `cmd/**`, `internal/**`, and `sdk/go/**`. The eight slice counts reconcile exactly to that baseline. At the final 2026-08-04 working-tree reconciliation, the requested roots contain 149 buildable packages (146 under `cmd/**` and `internal/**`, plus 3 SDK packages), 5,424 Go paths, and 28 untracked Go sources created by the implementation. The eight slice owners and the rows below classify those new sources; no current source remains outside the restarted audit.

The baseline proves the restart scope; it is not the final literal count. After source freeze, completion must:

1. enumerate every current Go source under the three requested roots;
2. assign every source added after the baseline to one of the eight slices;
3. rerun the package inventory for both modules;
4. append the final package/file totals and confirm that no source is unclassified;
5. refresh this document's statuses after the last review remediation.

The Go 1.26 `modernize` analyzer reported zero automatic findings in both modules. The remaining work is semantic. `dupl` reported 117 raw runtime candidates across 60 files and zero SDK candidates; none is actionable without a proven shared responsibility and canonical owner.
