Session list — give the title its line back

Each row now carries status, title, time, profile, subagent progress, thread fold and actions — all on the title's line. At the real sidebar width the title ends up with a sliver (“Ci…”, “Corrigir…”), worst with All profiles on. This board proposes a two-line anatomy where line 1 belongs to the title and every secondary signal moves to the meta line, plus inheritance rules that keep child rows short.

Proposed · v2 anatomy

  1. Line 1 is the title's. Only one 24 px slot shares it: compact time at rest, the “…” menu on hover/focus. Everything else that sat beside the title (owner plate, subagent chip, fold toggle) moves down.
  2. The meta line already had free space. “✳ general” uses ~60 px of a ~220 px line. Aux controls right-align there without touching the title.
  3. Owner is a glyph, not a plate. 14 px tinted glyph leads the meta line, roots only. Children belong to their root's profile, so repeating it is noise.
  4. Children inherit. A child whose agent, provider and profile match its parent drops line 2 entirely — the Issue fan-out becomes a compact list. A child that differs (Codex vs Claude) or needs attention keeps it.
  5. Children hang off a tree elbow. The straight rail becomes the same |_ connector nested tool calls use, so parentage reads at a glance and the last child is obvious.
  6. Provider marks keep their brand ink. Grey Claude and grey OpenAI marks are indistinguishable at 12 px; the runtime selector already shows them in colour, so the list matches it.
  7. Current plate covers the full row. Today the plate stops before the trailing chip and fold toggle, which reads as a clipped selection.

Bulletproof variants VC-12

Hostile but real inputs. Truncation priority on the meta line: secondary notes give way first, then the agent name (down to nothing when the line is full); the attention word, owner glyph, provider mark and the aux cluster never truncate. Full values stay in the accessible name and tooltip.

Implementation notes. The row becomes a stretched-target grid: the title button's ::after covers the row for navigation and the aux controls sit above it (z-index), so no interactive control nests inside another — the same constraint the current sibling layout solves. The accessible name stays the full title; truncated titles keep the existing tooltip. Keyboard focus on the row reveals “…” exactly like hover (VC-04), and the time keeps its <time datetime> with the full timestamp in the title attribute.
