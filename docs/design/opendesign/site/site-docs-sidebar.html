The contract: goal, verify, stop

A Loop is not a script and not a chat session. What makes it a Loop is a contract — a goal, a definition of done, a stop condition, and an iteration cap the daemon enforces. The runtime keeps every round durable and inspectable, so a Loop that ran overnight reads the same way in the morning: which nodes ran, what each produced, and why it stopped.

Two nouns, nothing else

The workspace surfaces exactly two things under one Loops umbrella: the catalog of definitions and the executions observed on the run page. Inline code reads as a chip: action, control, source.
