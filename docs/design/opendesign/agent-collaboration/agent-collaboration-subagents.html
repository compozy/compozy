What this board is

A subagent that works on its own branch shows where its work landed. When an agent delegates with isolation: "worktree", the subagent gets its own worktree and branch. Its card shows the branch while it runs. Once it settles, the card links to the pull request it opened, with the PR's state.

Hovering the card shows the worktree, the branch and its base, commits ahead, uncommitted files, the PR, and when CompozyOS last checked. CompozyOS observes these facts itself; it never takes the agent's word for them. If it could not check the PR, it says so instead of saying there is none.
