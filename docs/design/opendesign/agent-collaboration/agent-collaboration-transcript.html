What this board is

A message from another agent no longer looks like you typed it. When one session sends a message to another with compozy__session_prompt, the receiving transcript shows it as a left-aligned card: who sent it (provider mark + "From {title}", a link), how it arrived, whether a reply was asked for, and when.

On the sender's side, the send becomes a "Sent to" card that waits for the answer. The answer comes back as a "Reply from" card with its outcome. Your own prompts stay right-aligned bubbles, exactly as today.
