Agent collaboration

Three boards for .compozy/tasks/agent-collaboration/_uiux.md (spec: _spec.md) (S1–S5). A message one agent sends to another becomes a left-aligned card that names the sender, so it can never be mistaken for your own prompt. The sender sees a "Sent to" card that waits for the answer, and the answer comes back as a "Reply from" card. A subagent delegated into its own worktree shows its branch and the pull request it opened. Every board opens with what it is, which production components it changes, and the states it covers with their Visual Contract ids. The semantic contract is DESIGN-NOTES.md.
