Network — states

Gate, loading, and empty states for the redesigned Network surface. Copy is lifted verbatim from production (network-empty.tsx, daemon-down.tsx, threads-empty.tsx, directs-empty.tsx, thread-empty.tsx, direct-empty.tsx, use-active-session.ts). Gates render before the shell; in-channel empties render inside it.

01

Gate — Network disabled

Daemon status disabled. The whole route yields to one gate; no rail, no tabs. Admin-gated copy — the action opens Settings, it never enables Network inline.

Network is disabled.

An operator with admin access can enable Network availability. Local work remains available, and existing Network channels and history stay intact.

02

Gate — Ready, no channels

Status ready, zero channels. The empty state teaches the opt-in model instead of pointing at a blank list; creating the first channel is the primary act.

Network is ready when you are.

Executions stay Local by default. Choose Live explicitly for a future run to coordinate in channels, or open Settings to review Live defaults and ceilings. Network availability never enrolls an execution.

03

Gate — Daemon unreachable

Status query failed. Danger is carried by copy and the retry affordance — no red wash, no dead controls left behind it.

Network is unreachable.

Make sure the AGH daemon is running.

04

Loading — skeleton

Rail and thread rows shimmer in place of content — never a centered spinner. Shapes match the loaded layout so nothing jumps on arrival.

08

The composer authors as the channel’s local peer session. Without one, the input disables and the hint says exactly why (use-active-session.ts) — the disabled state explains itself, it never just grays out.
