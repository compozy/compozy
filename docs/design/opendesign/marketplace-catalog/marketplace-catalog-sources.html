What this board is

S5 — every plugin out there, in our list. Everything in the marketplace is an extension, and Compozy already installs Agent Plugins packages. What it cannot do yet is read a plugin marketplace — the marketplace.json document Claude Code, Codex, and Cursor users already point at. This board adds that: a marketplace is a source you register once (GitHub repository or local folder), Compozy fetches its plugin list on the catalog schedule, and each plugin becomes an Extensions entry under a section named after the marketplace. Compozy ships a short preset list so the official marketplaces are there on day one. Every plugin the document lists installs, whatever layout it keeps its manifest in (§04, Q1 decided).

Settings › Marketplace — one collapsible line per source

sources VC-01
Same grammar as skill sources. The Compozy catalog is the first line and is always on. Below it, the preset marketplaces Compozy recommends (on or off by default), then anything you added, marked custom. Closed, a line says name · count · switch. Open, it shows where it comes from, when it was last read, and how many of its plugins can be installed. Turning a marketplace off hides its section in Browse; already-installed plugins stay installed.
