What this board is

S1 — one Marketplace, one list, one kind. Everything in the marketplace is an extension: the packaged MCP servers are extensions that carry a server, and plugins from registered marketplaces are extensions too. So there is nothing to switch between. The window opens on the whole catalog; an installed entry simply reads “Installed” on its card. What you already have is a single line at the top — a row of logos and a count — and that line is the door to the Installed view (board 03). Sources are the only grouping: the Compozy catalog first, then each plugin marketplace you registered (board 05). Search narrows every section at once.
