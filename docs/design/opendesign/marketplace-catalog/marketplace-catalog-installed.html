What this board is

S3 — everything you installed, in one list, with the controls on the row. Click the installed line in Browse and the window drills into Installed. Every row keeps the card anatomy from board 02, adds what the extension contains (“1 MCP server · 2 skills”), and gains the controls that manage it — enable, authorize when its server needs it, update, remove. One line above the list says how many updates are waiting and updates them all. Search filters the list. Back returns to Browse.
