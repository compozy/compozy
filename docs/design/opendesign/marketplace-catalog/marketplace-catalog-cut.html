What this board is

S4 — one kind, and what that deletes. The marketplace stops having Skills and MCPs as things of their own. The 17 packaged MCP servers become extensions whose manifest carries the server: same card, same Install, and the inputs the server needs (an API key, a scope) are asked through the extension install flow. The one catalog skill, Documentation Writer, is retired; skills keep arriving inside extensions and from your folders. With no skills kind there is no skills search, so ClawHub goes. Public surfaces that named a kind keep working for one release and say what replaced them.

Where skills live now

cut VC-03
Skills stop being a thing you buy in the store. They arrive two ways, both already shipped: inside an extension (the Installed row says “2 skills”; the detail lists them), and from your skill folders, managed in Settings › Skills › Sources. Documentation Writer leaves the catalog. The session / picker and the skill activation rules do not change.
