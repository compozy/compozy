AGH Design System · Chapter 01

Foundations

The token layer every AGH surface is built from. One warm-dark ramp, one accent, hairline depth, Inter + JetBrains Mono. Production truth is packages/ui/src/tokens.css; the prototype-canonical mirror is design-system/ds-core.css — copy its :root verbatim into any new prototype. There is no light theme.

01

Surfaces & depth

Depth is a flat ramp plus hairlines — never drop shadows on content. Surfaces stack rail → canvas → canvas-soft → canvas-tint → elevated; separation comes from translucent-white hairlines. The only sanctioned shadows are --shadow-overlay (popovers, menus, sheets, toasts, modals), --highlight (inset top edge on primary buttons and active pill segments), and the shell-only window/dock shadows in ds-shell.css.

02

Signal palette & accent budget

Accent is the only hue with presence — and it is a state indicator, never decoration. It marks the primary action, live/running state, the current selection and active reasoning bars; it never washes cards, borders or backgrounds. Semantic colors appear as 6–12% tints with the tone color as ink. Data viz uses neutral --viz-* ink — charts never borrow signal colors.

accent#e8572a · action / running
accent-strong#f6874f · accent text on dark
success#5fbf85 · ok / idle / connected
warning#d6a647 · needs you / waiting
danger#e0635a · failed / destructive
info#8e8eb5 · tool calls / meta
neutral#7a7a80 · idle shapes, base pills
teal#225555 · wallpaper depth ONLY
R1Accent budget: per screen — one primary action, live dots, current-selection markers. A full-card accent border is decorative wash and is banned (running state = pulsing dot + pill, not a border).
R2Status is color + shape. The session vocabulary pairs each state with a distinct dot shape (circle, diamond, rounded square, hollow ring) so state survives color-blindness. See Components §01.
R3Tints carry tone ink. Pills and notices use --*-tint backgrounds with the tone color as text — never saturated fills.
R4#225555 (teal) is a registered brand tone used exclusively for wallpaper radial depth in the OS shell. It never appears in content, borders or controls.
03

Typography

Two families. Inter (display + body; features cv01 ss03) for UI chrome, names and prose. JetBrains Mono for everything machine-shaped: ids, slugs, counts, timestamps, durations, key-values, code — always with tabular-nums, subpixel-antialiased, letter-spacing 0. Body baseline is 13.5px / 1.5 / −.006em. Production medium weight is 510.

22px — sm buttons, filter chips, status pills, chips, switch (18h)

08

Focus & accessibility

A1Focus ring is the production contract: 0 0 0 2px rgba(255,255,255,.5) on :focus-visible (≥3:1). The 1px line-strong ring in pre-2026-07 prototypes is deprecated.
A2Pointer focus is quiet: fields on :focus-within only strengthen their border; the 2px ring is keyboard-only.
A3Real semantics: aria-pressed on pill segments, aria-current="page" on nav, aria-expanded on disclosures, role="dialog" aria-modal on modals, every aria-controls resolving to a real id, one focusable H1 per surface.
A4Touch targets ≥44px on mobile (window controls grow to 15px + 9px inset hit area; toolbar buttons to 44px).
A5data-od-id on every region, heading, control and repeated card users may point at.
