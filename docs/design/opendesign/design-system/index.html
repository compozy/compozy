AGH · Unified Design System · 2026-07

An operating system for agents

This folder is the single source of truth for every future AGH design and prototype in this workspace. It unifies the former systems/, catalog, settings and modal design-system files under the OS-shell direction: a 44px menu bar, a dock, floating windows with a unified head — and one warm-dark token system whose production truth is packages/ui/src/tokens.css. Start any new prototype by copying the :root from ds-core.css and reading GUIDE.md.

The twelve non-negotiables

01Copy tokens, never invent them. New prototypes paste the ds-core.css :root verbatim. Warm-dark only — there is no light theme.
02Accent is state or the primary action — one primary per screen, live dots, selection markers. Never borders, washes or decoration.
03Identity renders once — the 44px window head owns it. No legacy topbar, breadcrumb bar or route PageHead stacks.
04Two bars maximum per window: head + optional 38px tools strip. Route peer tabs sit after the title, in the head.
05Depth grows a breadcrumb, never a new window. Documents self-title with a state dot and never breadcrumb.
06Flat depth: surface ramp + hairlines. Shadows only on overlays, the inset highlight, and shell chrome.
07Radius waiver is shell-only (12–22px chrome); content stays 3–14px; the palette is mandatory everywhere.
08Lists assume scale: dense rows, hairline separators, sticky group headers, state-only color, Rows|Cards on every listing route.
09Reuse canonical components — RuntimeSelector, command-selects, DirectoryBrowser, the 7-bar meter. Forking a parallel geometry is a defect.
10Settings holds policy, not catalog; each section leads with its own information shape; plain language over mechanism keys.
11Truthful UI: every control and metric maps to daemon truth; missing data gets an honest placeholder; design empty/loading/error/degraded states.
12Linear-bar friendliness: approachable for non-operators — progressive disclosure (Advanced folds, Inspect drawers) instead of operator density on the surface.
