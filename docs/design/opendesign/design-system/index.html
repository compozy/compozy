CompozyOS · Unified Design System · post-#440

An operating system for agents

This folder is the single source of truth for every CompozyOS design and prototype in this workspace. Authority chain: packages/ui/src/tokens.css + web/src (production) → this folder → any older prototype. The :root in ds-core.css mirrors the post-PR-#440 token truth — warm-dark ramp lifted one step, radius rebased to 6/7/8/10/14/18, the type scale raised one legibility step, sentence-case eyebrows, system-font key caps. Start any new prototype by linking ds-core.css (+ ds-shell.css for shell surfaces) and reading GUIDE.md. The production primitive map lives in PARITY.md.

The twelve non-negotiables

01Copy tokens, never invent them. New prototypes link ds-core.css or paste its :root verbatim. Warm-dark only — color-scheme: dark is a product contract, not a preference.
02Accent is "act" — one primary action per viewport, live dots, attention badges. Never borders, washes, tab indicators, selection markers or decoration.
03Identity renders once — the 44px window head owns it. No legacy topbar, breadcrumb bar or route PageHead stacks.
04Chrome = head + optional 38px strip, plus the 37px deck while a window holds ≥2 tabs (≤119px loaded). Route views live on the strip, never in the head.
05Depth grows a breadcrumb, never a new window. Documents self-title with a state dot and never breadcrumb. Drilling never spawns a tab.
06Flat depth: surface ramp + hairlines + inset rings. Glass, blur and cast shadows are shell-chrome only (menubar, dock, window frames, overlays). Window-body content never casts.
07Radius ladder is 3/6/7/8/10/14/18/pill; the 12–22px waiver is shell-only. Selection is a neutral --elevated plate — --highlight rims buttons and pills only, never rows.
08Type: Geist 15px base, weights 400/510/600/620/700. Eyebrows are sentence case (12px/510); uppercase survives only as .eyebrow-caps (11px/600/+.06em). Mono = ids, code, fixed-width values — never row titles, never key caps.
09Reuse canonical components — check PARITY.md against @compozy/ui before authoring. Forking a parallel geometry is a defect; domain variants take domain-prefixed names.
10Signal color is information, never decoration. Rows and cards stay neutral at rest; tone lives in tints (6–12%) + readable ink, paired with text or shape. Charts use monochrome --viz-*.
11Truthful UI: every control and metric maps to daemon truth; missing data gets an honest placeholder; every surface designs its empty, loading, error and degraded states.
12Approachable by default: plain language over mechanism keys, progressive disclosure (Advanced folds, Inspect drawers), calm defaults — never operator-cockpit density on the surface.
