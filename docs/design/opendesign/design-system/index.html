CompozyOS · Unified Design System · shell v2

An operating system for agents

This folder is the single source of truth for every CompozyOS design and prototype in this workspace. Authority chain: packages/ui/src/tokens.css + web/src (production) → this folder → any older prototype. ds-core.css mirrors the shell-v2 token truth in both themes (:root = dark, the default; [data-theme="light"] = light): neutral chroma-free ramp, opaque hairlines, an inverted primary, Compozy orange for highlight and needs-you, Inter 425/500/600 with a 14.5px body, Geist Mono, radius 3/6/7/8/8/12/18/pill. Start any new prototype by linking ds-core.css (+ ds-shell.css for shell surfaces) and reading GUIDE.md. The production primitive map lives in PARITY.md.

The twelve non-negotiables

01Copy tokens, never invent them. New prototypes link ds-core.css or paste its :root and light block verbatim. Two themes, dark by default — every surface must read in both.
02Orange is "needs you" — attention badges, live highlights, the one highlight per viewport. The primary action is the inverted --primary pill; amber is only a real warning. Never borders, washes, tab indicators, selection markers or decoration.
03Identity renders once — the 48px window head owns it. No legacy topbar, breadcrumb bar or route PageHead stacks.
04Chrome = 48px head + optional 44px toolbar, plus the 40px deck while a window holds ≥2 tabs (≤132px loaded). Route views live on the toolbar, never in the head.
05Depth grows a breadcrumb, never a new window. Documents self-title with a state dot and never breadcrumb. Drilling never spawns a tab.
06Quiet depth: surface ramp + hairlines + the shadow whitelist (card · elevated · pop · overlay). No glass anywhere; tiled panes are flat, only floating windows, menus and popovers lift.
07Radius ladder is 3/6/7/8/8/12/18/pill (icon well 7); actions are pills. Selection is a neutral --selected plate — no rim, no accent.
08Type: Inter 14.5px body, weights 425/500/600 (620 display numerals); Geist Mono for code. Eyebrows are sentence case (12px/500); uppercase survives only as .eyebrow-caps (11px/600/+.06em). Mono = ids, code, fixed-width values — never row titles, never key caps.
09Reuse canonical components — check PARITY.md against @compozy/ui before authoring. Forking a parallel geometry is a defect; domain variants take domain-prefixed names.
10Signal color is information, never decoration. Rows and cards stay neutral at rest; tone lives in tints (6–12%) + readable ink, paired with text or shape. Charts use monochrome --viz-*.
11Truthful UI: every control and metric maps to daemon truth; missing data gets an honest placeholder; every surface designs its empty, loading, error and degraded states.
12Approachable by default: plain language over mechanism keys, progressive disclosure (Advanced folds, Inspect drawers), calm defaults — never operator-cockpit density on the surface.
