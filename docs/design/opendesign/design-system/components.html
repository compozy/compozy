Components

Every specimen on this page is live and composed from ds-core.css with no overrides — if a demo needs a page-local rule, that is a defect in the system, not in the demo. Use this chapter as the inventory: find the component, copy the markup, keep the geometry. Before authoring anything new, check PARITY.md against @compozy/ui — forking a parallel geometry is a defect, and domain variants take domain-prefixed names.

01Signal & status

State is the only thing allowed to carry color. Two dot families: .d for generic run state inside content, .status-dot for session lifecycle in rails and lists — the second one changes shape as well as hue, so state survives a monochrome screenshot and a red/green color deficiency.

.d--run + .d--pulse .d--ok .d--needs .d--fail .d--idle 7px · flex:none

.d is a 7px disc. --fail is hollow (1.6px inset ring), not a filled red dot — failure reads as an outline everywhere in the system. Pulse is cadence, not a state: it only ever rides on --run.

running · 3px accent halo idle · disc waiting · rotated square failed · square stopped · hollow ring

Shape is set by [data-status] on any ancestor, so a .session-row only declares its status once and the dot, the state word and the row tint all follow. Never style a status dot inline.

13Radio cards & choices

When an option needs a sentence to explain itself, it becomes a card. Selection is neutral: a --surface-glaze fill with an inset --line-strong rim, and the border goes transparent so nothing doubles up.

Accent never marks selection. If you need the selected card to shout, the problem is contrast in the glaze, not a missing accent border. The mono .choice__mode line is the escape hatch for operators — it names the exact config value without pushing jargon into the label.

14Session lists & transcript

The sidebar's session row is the densest object in the system: an 8px status column, a two-line body, and a right-aligned state word plus timestamp. Selection is a neutral plate — the accent rail was retired, because a running session already owns accent through its dot.

Group heads are sticky at 32px and stay on --rail so rows scroll under them cleanly. Collapse is a grid-template-rows: 1fr → 0fr transition, with visibility flipped at the end so hidden rows leave the tab order. Nested rows shrink to 28px.

The well is 48px with a 20px glyph; the title is 18/510 at -.022em. The framed variant adds a hairline and a 160px floor for empties that sit inside a panel. Error empties disclose the cause behind a fold rather than dumping a stack trace or hiding it entirely.

Skeletons mirror the geometry of the row they replace — same 34px well, same title and meta line heights — so the layout does not jump when data lands. The shimmer is cadence, not state feedback: 2s, off the motion ramp, and it stops entirely under prefers-reduced-motion.
