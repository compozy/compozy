AGH Design System · Chapter 03

Components

Window-content vocabulary — every class here ships in ds-core.css and mirrors an @agh/ui primitive. Reuse before create: in production code import from @agh/ui; in prototypes copy these classes. Domain variants take domain-prefixed names; never fork a parallel geometry.

01

Signal & status

State is carried by dots, shapes and tinted pills — color is never decoration. Session states pair color with a distinct shape: circle (running/idle), diamond (waiting), rounded square (failed), hollow ring (stopped).

02

Buttons

26px default, 22px small, radius 8. One primary per screen — accent bg + --accent-ink text + inset highlight. Destructive never competes with primary. Overflow is the last action, always icon-only with a label.

03

Fields & inputs

Three heights, three jobs: 28px search (context strip / toolbars, / focuses), 36px form input (modals, forms — production --height-input), 32px .ctl inline row control (settings rows only). Keyboard focus gets the 2px ring; pointer focus only strengthens the border.

04

Filter chips

Segmented chip: label · operator · value · × (22px, collapsed inner borders). One chip per field, AND across chips. Facets live here — never as kind-tab strips, never double-encoded in a pill-group.

status running
05

Pill-group & tabs

Pill-group = ephemeral view state (Rows|Cards, scopes) — recessed track, elevated active segment, never accent-filled. Underline tabs = content lanes: 30px compact .tabbar inside windows, 40px .lane-tabs on detail pages. Route peers (List · Kanban) are window-head tabs (.w2-tabs, chapter 02) — not content tabs.

06

Switch

32×18, knob 14, travel 14 — production geometry, verify-locked. On = accent track. A switch means the change applies immediately; draft settings use the save bar instead.

07

List rows

Full inventory row: grid 34px · 1fr · auto — neutral icon well, mono name + tags + slug, one truncated description, dot-separated meta; trail = stat block + pill + action. Compact rows (36px single-line) serve dense secondary lists inside windows. Lists assume many items: hairline separators, hover glaze, color only as state.

09

KPI · panel · runcard · viz

Every widget maps to persisted daemon data — nothing invented to fill a layout. Viz ink is neutral (--viz-*); signal colors never chart magnitude. Paired panels close flush — absorb height with real content, never air. Live runcards keep the standard border: running state is the pulsing dot + pill, never an accent border.

11

Session lists

Recent view: two-line rows (title + agent · state, mono time right). All-sessions view: 28px single-line rows under sticky agent group headers with hairline separators and per-agent collapse (data-collapsed animates grid-template-rows, persisted in localStorage). Neutral monogram chips — the status shape alone carries state.

12

Settings vocabulary

One row = one decision, stated as policy in plain language — mechanism keys live in the single Advanced fold as .provchip. Six row types: switch (immediate), select, number, action, link, read-only. Runtime facts are non-editable .tiles. Draft pages get the floating save bar; per-item surfaces get sheets; switches save themselves.

13

Intensity meter & chips

Reasoning effort renders as the 7-bar meter (bars 2.5×3→12px, fill accent-strong) — never glyph characters, never a dominant slider. In the runtime popover the whole reasoning control stays a quiet footer: accent appears only on the meter fill, the pressed effort pill and the selected model row.

14

Empty states & loading

Two copy paths: zero-inventory (CTA = the page primary) vs no-match (CTA = Clear filters). Loading is shimmer skeletons in the shape of the coming content — never spinners on whole surfaces.
