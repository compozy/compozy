AGH Design System · Chapter 02

OS Shell

AGH is an operating system for agents. The shell is three fixed zones — a 44px menu bar, a wallpapered desktop of floating windows, and a bottom dock — with Spaces per workspace and ⌘K as the universal entry point. Chrome lives in ds-shell.css under the radius waiver (12–22px); everything inside a window returns to the content scale. Reference behavior: os/os-v2.js.

07

Shell rules

S1Identity renders once per window. Never breadcrumb + accent tile + H1 stacks; the route PageHead is absorbed by the 44px head.
S2Two bars maximum — 44px head + optional 38px strip. The strip is tools only; route tabs never live there.
S3Route tabs sit after the title, left in the head; hidden on drill-in; absent without peers.
S4Depth grows a breadcrumb, never a new window. The trail is window-local (menu bar owns workspace, dock owns routes); status, actions and strip swap per level.
S5Document windows self-title with a pulsing state dot and never breadcrumb.
S6Sessions is a normal OS window — first dock icon, same WindowFrame as everything; no rail, no dock slide.
S7Minimize folds into the app's dock icon (dimmed glyph + hollow dot). No minimize tray. No desktop widgets — approvals live in the bell.
S8Settings opens from the menu-bar cog, not the dock. Dock mirrors production navigation 1:1 with group separators.
S9Accent in chrome = state or primary action only. The window glyph is neutral; live dots and the single primary button are the only orange in the frame.
S10Radius waiver is chrome-only (12–22px shell, content 3–14px) and never extends to color — the palette is mandatory everywhere.
S11State persists per space — window rects, wallpaper, minimized set, collapse states (localStorage, 250ms debounce). Keyboard: ⌘K palette · ⌘N session · ⇧⌘S spaces · Esc closes · ⌘[ back.
