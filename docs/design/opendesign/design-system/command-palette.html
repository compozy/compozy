CompozyOS · Design System · Chapter 04

Command palette

The ⌘K surface is the keyboard route into every window, entity and verb the daemon exposes. This chapter is the distilled anatomy — panel, rail, row ladder, chord tiers, view states, latency bands, forms, action panel, args and confirmation. The shell classes (.palette, .pal-*) ship in ds-shell.css; pieces the shell does not carry are prefixed .cp- in this page and mirror ../command-palette/command-palette.css exactly.

01Panel & zones

The palette is opaque — glass is retired. Its ground sits one step below the window ramp, so the overlay reads darker than the OS behind it instead of floating above it. The scrim is the only blur in the product.

10Density & motion rules

P1The row ladder is locked at 32px (44 for two-line entities). The 40px experiment made the root list unscannable — fewer verbs per screen, more travel per keystroke. Density is the point of a palette.
P2Anti-cockpit. No uppercase argument chips, no key-by-key diagrams, no operator ids in the row title. Machine truth demotes to mono ≤10.5px --faint — demoted, never deleted.
P3State feedback runs on 120 / 180 / 260 with cubic-bezier(.22,1,.36,1). Cadence is off that ramp: shimmer 1.6s, band sweep 1.2s, pending pulse 1.8s — loops, not state steps.
P4One motion channel per zone. A travelling sweep and a pulsing dot in the same band is two clocks arguing; the sweep wins and the dot stands down.
P5Reduced motion kills everything — entry spring, shimmer, sweep, pulse. Every state still reads from words, shape and tone alone.
P6Accent stays “act”: the busy sliver, the pending dot, the required mark. Selection is neutral --elevated; scope, groups and breadcrumbs never take accent.
P7Production parity: CommandDialog / CommandItem / CommandEmpty in @compozy/ui. Prototype divergence is a delta to annotate, not a fork to ship.
P8Truthful palette: a verb the daemon cannot run is either absent or disabled with its verbatim reason. No optimistic rows, no percentages the runtime cannot measure.
