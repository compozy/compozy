What this board is

S10 — two controls in Settings → Sessions. Follow-up behavior decides what Enter does while an agent is working: steer immediately (default) or queue until the turn ends. It is stored by the runtime, so the CLI and agent tools resolve the same default. Smooth streaming turns the reveal cadence on or off for this browser only — it never touches the runtime configuration.

04

One default, three surfaces

_dx.md · CLI · native tools
The setting is the daemon’s, so every surface reads it the same way. The composer hint (S1) mirrors it live; compozy session status reports it under busy_input.default_mode; an agent driver sees it in compozy__session_describe. Explicit verbs and flags always override it for one send.
Composer (S1)
⏎steer⌘⏎queue
CLI
$ compozy session status dev-loop -o json | jq .busy_input { "default_mode": "steer", "steer_delivery": "injected" }
config.toml
[session.busy_input] default_mode = "steer" # steer | queue queue_cap = 10
