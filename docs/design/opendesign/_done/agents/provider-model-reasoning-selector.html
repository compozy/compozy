Provider, model, and reasoning are one control.

This page mirrors web/src/systems/runtime/components/runtime-selector — the segmented trigger, the catalog popup, and the reasoning control share one focus lifecycle. Reasoning effort is picked with a range selector: drag the thumb, click a stop, or use arrow keys.

Contract. Each trigger segment is a real button that deep-links focus into the popup dialog: provider → rail, model → search + list, reasoning → range selector. The selector emits the canonical effort enum or "" for provider default. Escape closes and restores focus to the opening segment.

Trigger variants and states

Small

30px trigger for dense toolbars. Same anatomy, tighter segment padding.

Compact

Provider glyph and chevron only — the popup carries model and reasoning.

No model selected

An empty model is not a blank segment; the placeholder names the next action.

Read-only

Value stays legible while edits are disabled — identity is never erased.

Needs sign in

Auth problems surface on the trigger as a warning affordance, not silence.
