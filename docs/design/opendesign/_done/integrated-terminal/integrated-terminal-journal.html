03

Confidence — guesses are marked

US-023.AC-3 · exact / verified / estimated
Certainty is quiet; guesswork is marked. Two of the three chips are neutral, because being sure is the normal case and normal cases don't get a color. Only the guess carries the warning mark — and it is never dressed up as a fact. detected_by · US-023.AC-3
ConfidenceWhat it means
exact

CompozyOS started this command itself, so the record is first-hand — the command, the times and the result all come from the run.
verified

Someone typed it, and the shell confirmed the start and the end with a signature you never see on screen. Trusted the same way.
estimated

The shell said nothing, so CompozyOS worked the boundaries out from pauses in the output. Treat the timing and the result as close, not exact.
