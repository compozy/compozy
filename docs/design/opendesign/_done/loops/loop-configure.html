This loop watches until clean, so its iteration cap defaults to unbounded; set Max rounds to cap it (0 or blank = unbounded). Batches run sequentially by default; Max parallel branches (fan_out_width) raises concurrency once worktree isolation ships, bounded by the max_fan_out ceiling of 64. Each value is bounded by the daemon ceiling, a hard backstop that can't be raised here. Token and wall-clock budgets are opt-in and off by default (0 = unlimited); set budgets are enforced as a hard ceiling, checked before each node dispatch and at each generation boundary. When a budget is exceeded, halt ends the run as exhausted and escalate (this loop's default) pauses it as needs-approval for a human decision. Cost in USD is a display-only estimate, never a cap.
