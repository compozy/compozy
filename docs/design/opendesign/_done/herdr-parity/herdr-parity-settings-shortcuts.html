03

Terminal preset — preview, apply, revert

every displaced default shown · atomic · one-step revert
Preview is the contractThe preset applies as plain overrides, atomically (US-026.AC-1). The preview lists every change including displaced defaults — tab jumps move to ⌃⌥ digits so ⌘1…9 can drive desktops; the two bottom tiles step aside for session cycling. Collisions and layout hazards are flagged inline before anything is written (US-026.EC-1).
