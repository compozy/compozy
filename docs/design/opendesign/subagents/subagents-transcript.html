What this board is

A delegation becomes a live card in the parent's transcript. Where the agent hands work to a subagent, the generic "Used session spawn" row is replaced by one card: who is doing it (provider mark + status dot), what it is (title), what it is doing right now (latest step, or its result once done), and for how long. Clicking the card opens the subagent's session in this window.

Two or more delegations in the same turn fold into one group. Hovering or focusing a card shows its model, effort, status and a longer preview.

02

SubagentCard — anatomy and every state

transcript VC-02
One avatar, two lines, elapsed, chevron. Line 2 shows the latest step while live (the child's newest tool title or thought heading, at most once per second) and the result's first line once settled. When there is neither, line 2 shows the status word. The status word moves up next to the title only when line 2 is busy with progress or a result. A card never shows a terminal state it has not received.
5
  • 1SubagentAvatar 24px round tile, surface-2 + line-strong, 13px provider mark from the KindIcon registry; bot glyph when unknown. The 8px StatusDot sits bottom-right on a 2px canvas ring.
  • 2Title 12px, weight 510, fg-strong, one line, truncated. The full text is in the hover card.
  • 3Status word 10.5px subtle. Shown beside the title only when line 2 carries progress or a result, and never for Completed. Failed uses danger.
  • 4Line 2 11.5px muted, one line. Progress is coalesced to 1/s by the daemon. Whitespace is collapsed and generic endings are dropped.
  • 5SubagentElapsed mono 10.5px tabular. 7s · 12m 05s · 1h 03m. It is computed from the daemon's started_at and frozen at settled_at. It never starts from a browser stopwatch on mount.
  • 6Chevron only when child_session_id exists. Without a child session the card has no chevron and is not a button.
Eleven states. The dot follows StatusDot tones: mint pulsing while running, a hollow indicator ring while queued, accent for waiting for you, mint for completed, danger for failed, faint for canceled and interrupted. The words are fixed copy. Each card also has a word, so the state is never shown by colour alone.

SubagentGroup — same-turn delegations fold together

transcript VC-03
Two or more adjacent cards from one turn. Up to 3 overlapped avatars, then +N. The label counts subagents. The summary counts states in plain words, in info while any is live and in danger if any failed. Elapsed spans the first start to the last settle and is withheld while any end is unknown. Expansion is per window. A collapsed group where every subagent has settled dims to 62% and comes back on hover or focus.
