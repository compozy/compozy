Takes the tasks you already wrote, implements them one by one, reviews the work, and asks you before shipping.

Contract
Goal
Ship every authored task under .compozy/tasks/{{ .inputs.slug }}, implemented, reviewed to acceptance, and verified by the project's own checks.
Done means
All tasks finished, the review judge approved with evidence, and the project verification passed.
Verified by
Acceptance reviewan agent judge checks the work against each task, until clean
Project checkyour own command, {{ .inputs.verify_command }}
Your approvala human decision before anything ships
Possible endings
done · no_op · blocked · failed · exhausted · stalled · canceled
When something goes wrong
Steps retry on their own

Up to 3 tries with growing pauses. Steps that keep failing are set aside in quarantine, never lost. retry · backoff

Every step has a time budget

One attempt stops at 45m; the whole step at 2h. Nothing hangs silently. timeout · deadline

Waits stay visible

Waiting steps show their age, can remind the channel, and expire onto a fallback instead of waiting forever. wait · expires

You stay in control

Pause, resume, cancel or requeue any step from the run page. Cancel finishes in-flight work; Kill stops it now. cancel · kill
