What this board is

S3 — the one line that says what the agent is doing right now. It reads “Thinking…” from your send until the first word or tool, then “Working for 2m 14s · Running shell”, stays “working” while spawned agents still run, and after a stop reads “Stopped after 1m 40s”. There is never an empty reply bubble before content exists. The elapsed time is the daemon’s, so it survives a reconnect.

Stopped after 1m 40s — and the settled forms

US-027.EC-2 · US-027.AC-3 · task_07 VC-12
The row freezes into a sentence. A stop by you reads “Stopped by you after 1m 40s” in warning ink — the only tone this row ever wears besides danger for a real failure. 05

Quiet for 30 minutes — the session warns once, where you are

US-014.AC-1 · US-014.EC-2 · task_05 VC-01
No work signals for quiet_after (30m) means one warning, in the session itself, not only in the bell. It rides the existing notice slot at the top of the window (warning fill, no border) and the status row counts down to the stop (stop_grace, 10m). Any work signal clears both. The only action offered is one that exists: stop now. There is no “keep alive” because the runtime has no such verb — activity is what keeps it alive.
