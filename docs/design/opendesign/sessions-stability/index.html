Sessions stability

Seven boards for .compozy/tasks/sessions-stability/_uiux.md (S1–S10). The session window learns to tell the truth while an agent works: one control that is Send, Stop, or “Stopping…”; a queue you can see and edit; a status line that says what is happening and for how long; a chip when the live view is degraded; a transcript that reads as a story instead of a log; find and a message trail for long runs; two settings. Every board opens with what it is, which production components it changes, and the states it covers with their Visual Contract ids. The semantic contract is DESIGN-NOTES.md.

How to read a board
1 · Contract blockThree columns at the top: the surface in plain words · the production files it modifies, adds, deletes, or reuses unchanged · the states on the page, each linked, each with its VC id.
2 · Specimen + calloutsEvery specimen is a production-geometry session window or a flush component. Inverted numbered markers point at the element; the legend under it names the component, the token values, and the authority (production · spec · delta).
3 · TagsThe mono tag strip under each specimen: state · component · VC · tone / accent budget. Grep a VC id to find its specimen.
