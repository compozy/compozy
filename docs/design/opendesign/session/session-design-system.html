Session Transcript — Design System

The session surface is the product's center of gravity, and its job is to disappear behind the conversation. Everything rendered between messages — tool calls, thinking, markers, goal state, decisions, outcomes — is text on the canvas: one neutral ramp, one column, one disclosure motion, zero cards. Status is a glyph, never a badge. Color is a signal, never a wash.

01

Principles

  • Text first. The transcript owns no surface: no cards, no panels, no rails between messages. Prose sits directly on --canvas. If a component needs a border to exist, it probably shouldn't exist here.
  • One column. Transcript and composer share a centered 46rem column (--chat-col). Nothing inside is wider, narrower, or offset.
  • One neutral ramp. Hierarchy is carried by --fg → --muted → --subtle → --faint, never by color. Prose is --fg; tool activity is one step down.
  • Status is a glyph. Success = grey check. Failure = red ×. Running = grey spinner. Never a pill, never a badge, never tinted row text. Row text does not turn red on failure.
  • Color budget, exhaustive: the danger × glyph, +N/−N diff numerals, link color (--info), the running accent dot, and composer focus. That is the entire list. Tinted backgrounds (*-tint washes) are banned inside the transcript.
  • Collapse is the resting state. Settled work folds automatically; only the live tail stays open. Expansion is opt-in, remembered, and always the same 220ms disclosure.
  • Decisions leave the transcript. Permission and clarification prompts dock to the composer — where the answer happens. The transcript keeps one-line receipts.
  • Truthful lines. A collapsed row shows only what the daemon provides: verb, one input summary, status, diff stats, line counts. Per-tool duration is not in the data model — never render it. Turn duration is (turnDurationMs) — the fold row owns it.

Thinking & streaming

Live thinking is a shimmering text label — nothing else. Settled thinking collapses into the same row grammar as a tool call ("Thought for a while"), body indented and muted. The working indicator is three 4px dots on a stepped duty cycle plus a self-ticking elapsed label. No skeletons, no blinking caret, no pulse washes.

07

System events — markers, not banners

Every runtime event that used to render a tinted Alert card becomes a marker line: 12px glyph + one muted sentence. Tone lives in the glyph only. Lifecycle boundaries (resume, compaction) are a centered mono rule. The single exception: a session-level failure renders one hairline banner above the transcript — never between messages.

Markdown & code

Prose is 13.5px/1.62 with a compressed heading scale (h1 = 17px). Inline code sits on --badge-fill; fenced blocks sit on the 3% code wash with an optional quiet header (filename + copy). Links are --info, underline on hover only. Diff and stderr are colored text — never tinted blocks with rings.

Fold strategy

The renderer keeps one source of truth for row derivation. See session-timeline.logic.ts for the cluster rules — the short version:

  • consecutive calls with the same turnId cluster
  • narration flushes the run

  • Heading scale is compressed — a chat reply is not a document; h1 17px → h4 13.5px.
