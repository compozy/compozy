What this board is

S1 — every automation in one list. Jobs and Triggers used to be two dock apps with two lists. Now there is one window, Automations. The first control on the toolbar answers the only question that differs between them, how it starts (All · Scheduled · On events). Each row reads as a sentence, says when it runs next or last ran, and can be turned on or off without opening it.
