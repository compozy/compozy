What this board is

S3 — one dialog makes any automation. You answer two questions in plain words: when does it start (on a schedule, when something happens, or when another app calls a link) and what does it do (ask an agent, start a Loop, or create a task). The first answer decides, out of sight, whether the daemon stores a job or a trigger. A sentence at the top rewrites itself as you go, so you can read what you are about to create before you create it.

04

Edit — what is locked and why

editor VC-04
Locks explain themselves. The daemon can't change a target kind, an agent, a location, or turn a job into a trigger. So in edit mode the unchosen Starts and Does cards read disabled, with one reason line. The chosen ones keep their settings editable. Production disabled the controls silently.
