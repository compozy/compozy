What this board is

S2 — open an automation and see three things: what it does (in one sentence), whether it is on, and whether the last runs worked. The page is the same whether it starts on a schedule, on an event or from a webhook. Only the Starts row changes, and schedules gain Run now. Everything a developer needs (ids, cron, scheduler state, the raw envelope) is still there, one click away in Inspect.
