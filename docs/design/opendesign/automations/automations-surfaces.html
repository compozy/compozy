Dock — two launchers become one

surfaces VC-01
One fewer icon in group 2. Tasks · Loops · Automations. The bolt (the old trigger glyph) becomes the Automations mark and is used for nothing else. It is the common sign for "this runs on its own". Inside the window the start kinds get their own glyphs: the clock for schedules, radio for events, webhook for links, so a row never repeats the app mark. The open-window dot follows the single window.

05

Old links + saved desktops

surfaces VC-05
Nothing a user saved breaks. Bookmarks, notification links and open windows in saved desktops keep working. Routes redirect for one release (public regime). Saved layouts are user state: a stored-layout migration rewrites the app id and the route, and if both windows were open both stay, as two Automations windows. Closing one would lose its path.
