Composer context control

session-context-composer.html · S1 · S2 · 2026-09-11

How full is the window, at a glance. A 16px ring joins the composer's left cluster, after the model and folder chips. It fills with what the agent last reported (used / size), turns warning-toned only when Compozy is about to compact, and stays plainly unknown for agents that never report. Hover or focus reads the numbers; a click opens the Context rail. Read the contract block, the five specimens, then the dictionary. Content is illustrative; runtime truth owns values.

What this board is

The context meter in the composer and its tooltip. One ghost icon button with a ring. The arc is the agent's reported fill; the tooltip is three lines at most: numbers, state and turn, and the compaction sentence when it applies. Nothing on the row moves: the control takes the slot after the environment chip and wraps with the cluster. It never shows 0% for an agent that has not reported — the ring is dashed and the label says so.

US-001.EC-1 EC-2 EC-3 EC-5 · US-002.EC-1 · VC-04
Four honest variants of the same control. Stale: the last report belongs to an older turn — dotted arc, subtle ink, the tooltip says "stale · as of turn 11". Estimated size: the agent sent used but no window; the daemon filled size from the model catalog — the arc is normal, the tooltip adds "window from model catalog".   • Slot. Left cluster, after environmentControl, before Attach; 24px; wraps with the cluster; reserved while the first read is pending.
  • Data. useSessionContext: usage query (enabled while the window is live) + the latest transcript usage part for used/size/turn; every other field from the query.
  • Click. useSessionInspectorState(sessionId).setOpen(true) — the topbar toggle reads pressed; no second flag.
  • Warning. ratio ≥ context.pressure_threshold; absent threshold → no tone, no sentence.
  • Never. 0% for unknown; percent without both numbers; a HoverCard; reuse of IntensityMeter.
  • Format. 89.7K · 1.2M · percent rounded, one decimal under 10%; lib/context-format.ts.

Reference sources: emdash context-usage-indicator.tsx (donut + size > 0 gate), t3code ContextWindowMeter.logic.ts (reserve the slot), Zed thread_view.rs render_token_usage (ring + tooltip rows, 0.85 warning), Synara contextWindow.ts (latest snapshot).
