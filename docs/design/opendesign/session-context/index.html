Session context

Two boards for .compozy/tasks/session-context/_uiux.md (S1–S5). A context meter joins the composer and reads the agent's report; a click opens the right rail, which becomes one tab-less Context body: an honest three-tier bar (Compozy context ≈ · Agent & conversation · Free), what Compozy sent per section, tokens and cost with provenance, the turn history with compaction markers, and the session's activity. Memory, Files and Vault leave the rail. Every board opens with what it is, which production components it changes, and the states it covers with their Visual Contract ids. The semantic contract is DESIGN-NOTES.md.

How to read a board
1 · Contract blockThree columns at the top: the surface in plain words · the production files it modifies, adds, deletes, or reuses unchanged · the states on the page, each linked, each with its VC id.
2 · Specimen + calloutsProduction-geometry session window or a flush rail. Inverted numbered markers point at the element; the legend names the component, the token values, and the authority (production · spec · delta).
3 · Tagsstate · component · VC · tone / accent budget under each specimen. Grep a VC id to find its specimen.
