01

The control

one 28px toggle owns scope — everything else derives
PlacementDirectly after the workspace chip, before the app menus — the menu bar owns workspace, so it owns scope. 28×28, radius 7, house glyph 15px (the mode points at ~). Same footprint as .mb-icon; never in the right tray — the tray stays bell · ⌘K · cog.
.gw-toggle · 28px
SemanticsOFF → scope is the selected workspace; the chip shows it. ON → scope is Global (~); the chip swaps to the house identity. The workspace selection is remembered underneath — toggling off returns to it. New sessions, tasks, agents, installs all land in the active scope.
⇧⌘G toggles · also in ⌘K as "Turn on Global scope"
02

States

pressed = the one accent instance · chip stays neutral
Off · restingQuiet subtle ink, no fill. Workspace chip carries the identity — production verbatim.
Hover · tooltipHover fills --btn-fill, ink to strong — same pair as every menubar control. Tooltip names the mode and its root; while ON it flips to the off-statement ("Back to compozy").
OnAccent tint fill + accent-strong ink + 1px inset accent ring — the single accent instance of the global state. The chip swaps to house glyph + Global; the workspace name leaves the bar (the chip never shows a scope that is not active). Click the toggle in this demo — it works.
Focus2px accent :focus-visible ring, 1px offset — keyboard path is first-class (⇧⌘G lives here).
03

Zero workspaces

the fallback is Global — "No workspace" dies
Locked-onWith no registered workspaces, global is on and the toggle is locked-on (tooltip carries the reason). The old "No workspace" chip and the arbitrary workspaces[0] fallback are deleted — first-run users land somewhere real: ~.
04

Mobile (<960px)

the toggle survives the reflow — scope must stay reachable
KeptMobile menubar order: logo · workspace chip · toggle · bell · ⌘K · cog (app menus already hide). The toggle is the only left-cluster control besides the chip, so it fits; 28px stays above the 44px hit target via the existing padding halo.
