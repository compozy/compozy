Global workspace · one scope toggle

Design references for retiring the four disconnected encarnations of "global" — the pinned Home workspace row, the Use global workspace setup card, the Global|Workspace pill-groups and the install-sheet radios — in favor of one menubar toggle that owns scope. ON → everything lands in ~ (Global); OFF → the selected workspace. Every other surface derives the target and states it. Start at the audit; contract and production change map live in DESIGN-NOTES.md.
