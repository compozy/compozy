QA impact 2026-11-10 (review fixes R3, R4): the sidebar lives in the docs layout, so opened folders and its scroll position survive navigation within a section; a folder with a landing page is a real link plus a separate toggle; a drawer left open closes when the viewport reaches `lg`; the current section tab is scrolled into view on narrow screens; "On this page" scrolls its own rail and marks the last heading at the end of the page. A failed search shows "Search is unavailable right now." with Try again and is not cached. Enter opens the highlighted result, also right after a section filter changes the results.

QA result 2026-11-10 (R4 walk, `next start`, 1440 and 390, dark): pass. Seven section tabs with counts, the current one selected and visible at 390; the sidebar lists only the current section and marks the current page; a folder opened and the rail scrolled to 216px both persisted after navigating to `/docs/loops/catalog/`; all nine draft states render without overflow (the draft itself overflows on hub and config at 390); masthead breadcrumb, numbered steps, prompt lines with copy, Copy as Markdown (the page's Markdown), previous/next; Mermaid renders; anchors and a hard-loaded `#state-machine` land under the header. The ⌘K palette groups results by section, filters by section, moves with the arrow keys, finds body text, closes on Escape, and shows the error state and recovers on Try again (route answered 500, then served). Defects fixed during the walk: after a section filter no result stayed selected, so Enter did nothing (now 6 of 6 runs open the first result); a Mermaid caption showed literal backticks.
