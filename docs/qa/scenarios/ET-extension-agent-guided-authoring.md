Added by ext-improvs Task 09 (Phase G official skill). Planning flag only; no QA session ran.

R10's agent-as-author bar: give a Compozy agent a plain request ("build me an extension that does X")
and let the skill router carry it. The agent must reach `references/extension-authoring.md` from the
router without being told the filename.

Assert the authoring outcome: identity, input schema, permissions, and any command block declared
once in code; the manifest generated by `extensions_build`, never hand-written; `extensions_validate`
run and its `consent_areas` reported to the operator before any install is proposed; a permission
outside the closed 87-method set refused rather than invented; `bridge.adapter` never scaffolded.

Assert the operating discipline: native tools only, `extensions_dev`/`extensions_reload` called with
a `generation_hash` from a prior `extensions_build` rather than a path, interaction gates approved
in-band, and structured fields reported instead of prose.

Failure lanes worth exercising: a build that fails command-tree or flag-projection validation, a
reload whose new generation fails to activate, and an agent asked to inspect a dev instance through
`extension list` (which reads the global set only).

Dedup: ET-compozy-official-skill-discovery owns skill discovery and catalog identity;
ET-extension-code-first-authoring owns the operator-driven template path. This file owns the
agent-guided authoring outcome.
