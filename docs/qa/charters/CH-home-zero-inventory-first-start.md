# CH-home-zero-inventory-first-start: Prove a first-run Home offers one honest start, not seven empty panels

```yaml
charter:
  id: CH-home-zero-inventory-first-start
  mission: "As Lea meeting Compozy for the first time, open Home on a workspace where nothing has run and prove the screen offers one heading and three starts she can actually take — and that the seven zones come back, permanently, the moment real work exists."
  mode: charter-with-tour
  persona:
    name: Lea
    device: laptop
    network: wifi-fast
    locale: en-US
  journey: J-operate-home-dashboard
  scenarios: [RT-home-zero-inventory-first-run]
  tour: Feature Tour
  time_box_minutes: 60
  guidance:
    must_try:
      - "Arrive at Home with no prior knowledge of the product and read the screen aloud: is the primary action unmistakable, in words a first-timer already owns, with no runtime noun and no explainer paragraph under the heading?"
      - "Take each of the three starts in turn — Start a session, Create a task, Browse the marketplace — and confirm every one lands somewhere real that accepts work, not a dead route or another empty catalog with no next step."
      - "Time the first start against Lea's 60-second patience. If choosing among the three is harder than just starting work, or if a start dumps her into a form she cannot fill, the design failed the arrive-and-use bar."
      - "Watch for the two first-run anxieties this surface must answer or defer honestly: what is this going to do, and how do I stop it. Nothing here may promise a capability that is not there."
      - "Follow one start to completion, return to Home, and confirm the seven zones replaced the zero state and it does not flicker back on reload."
      - "Prove the four ways the zero state must NOT appear: an agent already working (has_live_work), a pending approval, a run closed today, and a pulse bucket outside today. Each keeps the zones — telling that person nothing has happened would be a lie."
      - "Read the state in a project workspace and in Global: the heading names the workspace in a project scope and stays generic otherwise."
      - "Resize to 1280 and 768 — the heading and three actions must stay one calm group at the 15px baseline, not wrap into a ragged stack."
    must_avoid:
      - "The populated seven-zone read, the usage window, and the attention approve/reject path — CH-untested-069-operate-home-dashboard-cora owns those, as Cora."
      - "Tasks, Jobs, and Triggers zero-inventory catalogs — CH-empty-catalog-first-use owns them as this cycle's adjacent canary."
      - "The onboarding setup panel itself — CH-untested-019-19-lea owns Lea's pre-desktop first run; this charter starts after the desktop is live."
      - "Filing token or spacing nits from the global type lift; CH-plain-scale-legibility owns the scale."
```
