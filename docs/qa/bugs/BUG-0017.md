## Regressed (2026-08-20)

The daemon-served Web build rejected the command catalog and Window Manager client during desktop
bootstrap because required empty collections encoded as JSON `null`. The palette tried to flatten a
null binding collection, and client registration retried because `global_shortcuts` failed the Web
contract. The desktop never reached a usable command surface.

- **Report:** `docs/qa/reports/2026-08-20-command-palette.md`
- **Root cause:** API converters cloned nil Go slices into nil destination slices. JSON therefore
  emitted `null` for required array fields instead of `[]`.
- **Fix commit:** `c3c50b6`
- **Regression test:** `internal/api/contract/contract_test.go` —
  `TestCmdPalettePayloadJSONShape` and the required-client-collections case in
  `TestWindowManagerV3WireContract` failed before the converter fix and pass afterward under
  `-race`.
- **Retest:** The daemon-served Agents journey passed after the repair; original settings personas
  remain scheduled in this run before the bug returns to `verified`.
