# BUG-0019: Disabled dev-cycle tools remain visible in the operator catalog.

- **Status:** verified
- **Impact (user-side):** Trust-Damage
- **Severity:** High · **Priority:** P1
- **Persona Affected:** Operator / Agent
- **Journey Step:** J-01 Default dev-cycle launch and delivery, step 1
- **Scenarios:** ET-052
- **Found:** 2026-07-06 · **Report:** `docs/qa/reports/2026-07-06-loops.md`

## Summary

An operator disables the `dev-cycle` extension and sees its Loops and agents leave the catalog, but the extension tools still appear in `agh tool list/search/info`. The package looks partly disabled and partly available, which violates the all-surfaces leave/return contract.

## Reproduction

- **Charter:** CH-001 · **Tour:** Feature + Garbage
- **Environment:** laptop / Wi-Fi / en-US, deterministic QA lab

1. Start the deterministic lab and confirm `dev-cycle` is active.
2. Run `agh extension disable dev-cycle`.
3. Check `agh tool list -o json`, `agh tool search dev_cycle -o json`, and `agh tool info ext__dev_cycle__coderabbit_fetch_unresolved -o json`.

**Expected:** Disabling `dev-cycle` removes its extension tools from operator-visible tool catalogs, and enabling it restores them.
**Actual:** The disabled extension tools remained visible to the operator with unavailable diagnostics.

## Evidence

- Before fix: `docs/qa/evidence/2026-07-06-loops/ch001-cli-tool-search-disabled.json` and `docs/qa/evidence/2026-07-06-loops/ch001-cli-tool-info-disabled.json`
- After fix: `docs/qa/evidence/2026-07-06-loops/ch001-fixed-tool-search-disabled.json` returns zero tools, and `docs/qa/evidence/2026-07-06-loops/ch001-fixed-tools-disabled.json` contains no `ext__dev_cycle__*` IDs.

## Fix

- **Root cause:** `ExtensionToolProvider.manifestTools()` indexed manifest-authored extension tools even when the installed extension registry entry was disabled; availability later marked them unavailable, but the operator catalog had already included them.
- **Fix commit:** pending local diff
- **Regression test:** `internal/extension/tool_provider_test.go` (`TestExtensionToolProviderCatalog`) plus `go test -race ./internal/extension -run 'TestValidateDaemonCompatibilityNormalizesDaemonBuildVersions|TestExtensionToolProviderCatalog|TestExtensionToolProviderAvailability' -count=1`

## Verification

- **Retested:** 2026-07-06, same persona/journey · **Report:** `docs/qa/reports/2026-07-06-loops.md`
- **Result:** Disabling `dev-cycle` removed its Loops and extension tools from the public catalogs; enabling it restored `reviews-watch`, `software-delivery`, and the three `ext__dev_cycle__*` tools.
