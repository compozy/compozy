# BUG-0026: QA bootstrap used an obsolete real-scenario skill path

- **Status:** fixed
- **Impact (user-side):** Blocks-Completion
- **Severity:** High · **Priority:** P1
- **Persona Affected:** QA operator
- **Journey Step:** Task 04 isolated-lab bootstrap
- **Scenarios:** model-selector QA infrastructure
- **Found:** 2026-07-10 · **Report:** `docs/qa/reports/2026-07-10-model-selector.md`

## Summary

The fresh-lab bootstrap and playbook loader hardcoded `.agents/skills/real-scenario-qa`, but the installed canonical package is nested at `.agents/skills/agh/real-scenario-qa`. Task 04 could not load or validate its selected playbook.

## Fix

- **Root cause:** Multiple scripts duplicated a stale flat path instead of resolving the installed skill location centrally.
- **Fix commit:** pending local diff; the user explicitly requested no commit.
- **Production fix:** `.agents/skills/agh/agh-qa-bootstrap/scripts/qa_skill_paths.py` owns skill-path resolution; bootstrap and playbook loader use it; the smoke test loads a real playbook.

## Verification

- Bootstrap smoke test passed.
- `devtool-oss-launch` validated with 8 agents, 5 channels, and 11 tasks.
- The fresh lab and manifest were created successfully.
