# BUG-0022: reviews-watch sends raw input templates to the watch-source poller

- **Status:** fixed
- **Impact (user-side):** Blocks-Completion
- **Severity:** High · **Priority:** P0
- **Persona Affected:** Bruno
- **Journey Step:** J-08 Run a watch-source Loop that self-corrects and concludes on its own, step 1
- **Scenarios:** LP-029
- **Found:** 2026-07-09 · **Report:** docs/qa/reports/2026-07-09-loops-refac.md
- **Origin:** n/a

## Summary

`reviews-watch` starts with a `watch-source` node whose `watch.pr`, `watch.poll_interval`, and `watch.quiet_period` fields are templates over loop inputs. The coordinator passed `node.watch` directly to the extension poller without runtime rendering, so the dev-cycle extension received the literal string `{{ .inputs.pr }}` and failed PR normalization before it could watch CodeRabbit events.

- **Charter:** CH-005 · **Tour:** Interrupt Tour
- **Environment:** Bruno / desktop / wifi-fast / en-US; fresh isolated QA lab `loops-refac-task-16-20260709-20260709-034751-043179`.

1. Start the isolated daemon with the bootstrap env from `docs/qa/reports/2026-07-09-loops-refac.md`.
2. Register the lab workspace as `ws_d53a1db33bdbbb73`.
3. Start the reviews-watch loop:
   `agh loop run --name reviews-watch --workspace ws_d53a1db33bdbbb73 --input pr=1 -o json`
4. Wait for the watch-source poll cycle.
5. Inspect daemon logs.

**Expected:** The poller receives a rendered watch spec with `pr: "1"` or `pr: 1`, then either waits for CodeRabbit activity or reports the next real environment prerequisite.  
**Actual:** The poller receives raw template text and fails with `dev-cycle: pr must be numeric: strconv.Atoi: parsing "{{ .inputs.pr }}": invalid syntax`.

## Fix

- **Root cause:** `evaluateWatchSourceNode` used `node.WatchSpec` directly, while action params and other runtime-evaluated loop fields render through the runtime namespace.
- **Fix commit:** `f659c457` (`feat: loops refac finish`).
- **Production fix:** `internal/loop/coordinator_watch.go` now builds the runtime namespace and renders `node.watch` through the same recursive rendering path used for node params before calling the watch-source poller.
- **Regression test:** `internal/loop/coordinator_watch_test.go`: `Should render watch source spec templates before polling`.
