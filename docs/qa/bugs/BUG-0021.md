# BUG-0021: Software-delivery fails before load_tasks because an input source node is executed as an action

- **Status:** fixed
- **Impact (user-side):** Blocks-Completion
- **Severity:** Critical · **Priority:** P0
- **Persona Affected:** Bruno
- **Journey Step:** J-01 Run a default dev-cycle Loop to a verified finish, step 4
- **Scenarios:** LP-003;LP-046
- **Found:** 2026-07-08 · **Report:** docs/qa/reports/2026-07-08-loops-refac.md
- **Origin:** n/a

## Summary

Bruno can start the `software-delivery` loop, but the run never reaches `load_tasks` or the gated `run-agent` session. The daemon creates a task run for the `slug_input` node even though that node is a `source`/`input`, claims it as `loop-action`, and fails it with `node "slug_input" is "source", not "action"`. The loop retries into a second generation and repeats the same failure.

## Reproduction

- **Charter:** CH-026 · **Tour:** Feature Tour
- **Environment:** Bruno / desktop / wifi-fast / en-US; fresh isolated QA lab `loops-refac-task-16-20260708-130224-745100`.

1. Start the isolated daemon with the bootstrap env from `docs/qa/reports/2026-07-08-loops-refac.md`.
2. Register the lab workspace as `loops-refac-task-16`.
3. Run:
   `agh loop run --name software-delivery --workspace loops-refac-task-16 --input slug=loops-refac -o json`
4. Inspect the returned run:
   `agh loop status --workspace loops-refac-task-16 --run-id looprun-d8712cd01653cc23 -o json`
5. Inspect the failed task runs for `slug_input`.

**Expected:** The input source node resolves the provided `slug`, `load_tasks` runs through `ext__dev_cycle__import_tasks`, and the run reaches the gated `execute_task` path.  
**Actual:** `slug_input` fails as a daemon-claimed task run with `loop: validation failed: node "slug_input" is "source", not "action"`, so the run never reaches `load_tasks` or any gated session.

## Fix

- **Root cause:** `source/input` nodes were not treated as coordinator-owned nodes. The coordinator reserved them as ordinary worker/action task runs, and the loop-action executor then rejected the node because `slug_input` is a `source`, not an `action`.
- **Fix commit:** `dfadc766` (`feat: loops refac until task 12`).
- **Regression test:** `internal/loop/coordinator_test.go` (`TestCoordinatorRunnerShouldResolveInputSourceNodes/Should complete input sources without queuing action task runs`).
