## Summary

Maya could open the first public thread, but only after repeated failed native and CLI sends plus a secondary lookup of the bundled AGH Network reference. The primary native descriptor marks only `workspace_id`, `channel`, `kind`, and `body` as required, leaves `body` as an unconstrained object, and does not explain the conditional `surface`/conversation fields. The CLI then requires `--surface thread` and `--thread`, but its help does not state the accepted `thread_...` identifier grammar or that the first valid send creates the thread.

The persisted thread and messages prove that runtime behavior is correct once the hidden contract is guessed. The defect is the agent-operable contract: reasonable inputs fail with generic `tool_invalid_input` or `invalid field` responses before the agent discovers the missing identifier convention elsewhere.

## Fix

- **Root cause:** The runtime correctly implements implicit public-thread creation and validates `thread_id` against `^thread_[a-z0-9][a-z0-9_-]{2,95}$`, but that contract was not co-shipped to the primary agent-operable surfaces. The native descriptor omitted the grammar and conditional field requirements, the CLI help omitted the grammar and first-send behavior, the CLI deferred identifier validation to the daemon, and OpenAPI plus the normative protocol exposed weaker string shapes than the runtime accepted.
- **Fix:** Export the canonical Network identifier patterns; describe the conditional surface/container/body/work contract and first-send creation in the native descriptor, CLI help, OpenAPI, normative protocol, and bundled AGH skill; validate CLI conversation IDs locally; regenerate the native catalog, OpenAPI/TypeScript contracts, and CLI reference. The safe Hosted MCP error mask remains unchanged.
- **Fix commit:** `f6748f2f`
- **Regression test:** Red-first cases now pass in `internal/tools/builtin/builtin_test.go`, `internal/cli/network_test.go`, and `internal/api/spec/spec_test.go`. Existing `internal/network` and CLI integration suites continue to own identifier validation and first-send persistence without duplicating the runtime invariant.
