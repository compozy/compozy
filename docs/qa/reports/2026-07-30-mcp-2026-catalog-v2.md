- **Figma:** product decision for this tranche. Its official remote server is current, but Figma states that only catalog-listed clients may connect; Compozy is not being represented as an approved client in this change. See [Figma MCP introduction](https://developers.figma.com/docs/figma-mcp-server/) and [remote setup](https://developers.figma.com/docs/figma-mcp-server/remote-server-installation/).
- **Shopify:** current official commerce MCP endpoints are store-specific and use UCP/client-credential contracts. The existing catalog cannot safely express a per-store host/path or mint the required JWT through the current install contract. See [Storefront MCP](https://shopify.dev/docs/apps/build/storefront-mcp/servers/storefront) and [Order MCP](https://shopify.dev/docs/agents/orders/order-mcp).
- **Slack:** the official server is current, but Slack requires every MCP client to be backed by a fixed registered Slack app; it does not support Dynamic Client Registration. A generic curated entry would be unusable without Compozy app registration and admin approval. See [Slack MCP server](https://docs.slack.dev/ai/slack-mcp-server/).
