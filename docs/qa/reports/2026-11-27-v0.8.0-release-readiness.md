## Pre-publication installer dependency

The signed SSH installer verifies the release checksum and Sigstore bundle before it connects to the host. Both v0.8.0 release files returned HTTP 404, and GitHub reported that the release had not been published. The v0.7.8 Linux archive matched its published digest. A manual RC installation can exercise runtime behavior, but the signed v0.8.0 installer needs a separate run once these assets exist. [SSH setup order](../../../internal/computers/sshsetup/runner.go)

## Defect triage

The web bundle pinned on main (`v0.0.840`) failed `webAssetsCheck`. On a fresh signed-out home its UI reached the generic error screen. Building the web source with Vite produced digest `875a94cfad5b0c45e9a7b5ce5ebb0805bb17678ab0a4fa9bbb37d458c57f470d`. That digest matches the `v0.0.875` bundle already pinned by release PR #2055 at `6766f11d62b5f672a75e80c78e4f64d9d1c1701c`. Rebuilding the same daemon with that pin and reloading the same home produced the sign-in screen above. The release PR already carries the correction. No additional product defect was confirmed in the completed checkpoints. [Release PR](https://github.com/compozy/compozy/pull/2055)
