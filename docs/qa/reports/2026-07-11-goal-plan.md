## 7. Coverage taxonomy sweep

1. **Journeys:** four complete value flows cover all eight QA seed behaviors, each with true end state and abandonment. Covered by J-26..J-29.
2. **Functional:** exact HTTP status/body/content type, one-live CAS, controls/grants, pagination/nullability, editor lints, tool availability, and recovery outcomes ride inside GL rows/charters. Covered.
3. **Experiential:** Lea owns first-use clarity; Marina owns mobile observation; Sol owns keyboard/screen-reader/reduced-motion; Task 08's lens pass re-walks J-26 and J-27. Covered.
4. **Edge/error/empty:** invalid/oversized start, null snapshot, busy draft, stale replace, clear, silent/stale usage, network drop, daemon restart, and ambiguity are explicit branches. Covered.
5. **Cross-cutting:** workspace isolation, HTTP/UDS/CLI/native consistency, reconnect continuity, mobile observation, accessibility, config restart/pinning, and snapshot immutability are mapped. Editor mobile authoring is a deliberate skip because the product editor is desktop-only; Marina verifies the read/approval surface on mobile.

No taxonomy dimension is silently skipped.

## 9. Truthful-UI and public-surface release bar

- No fabricated context percentage; `unknown` and `pending` remain distinct.
- Chip turn count/effective limit equals snapshot and turn audit.
- Usage/budget exhaustion never renders Complete; terminal blocked never offers Resume.
- Work, continuation, and compaction transcript tags come only from persisted metadata.
- Replace prefill carries the exact expected Run; stale/failure leaves the current Goal visible.
- Direct structured Goal results never enter the AI stream decoder.
- External start/replace/clear/reseed is discovered from null without polling.
- Every deterministic control/report/filter/lint error remains visible and machine-readable.
- Web evidence is independently confirmed through CLI/API/UDS; optimistic state alone cannot pass.
