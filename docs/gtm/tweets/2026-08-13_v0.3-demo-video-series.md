## Voice gate notes

All 19 drafts (17 demos + 2 bracket posts) score below the blocking threshold of 3 under `x-pedro-voice`.

- **Em-dashes:** 0 across every draft. This was the highest-risk pattern given the source material (release notes use them heavily).
- **AI vocabulary:** 0 (`comprehensive`, `robust`, `seamless`, `leverage`, `showcase`, `underscore` all absent).
- **Banned openers:** 0. Demo 7 uses `shipped a…`, adjacent to the `^just shipped` approvelist shape.
- **Rule of three:** deliberately avoided. Enumerations were cut to two items or rewritten as clauses. The release notes' natural three-item lists were the main rewrite pressure.
- **Negative parallelism:** three drafts use a single `X, not Y` contrast (demos 1, 2, 9). Single contrast, not the formulaic `not just X, it's Y` shape.
- **Hedging:** 0 across all drafts.
- **Emojis:** 0. A product account posting proof footage does not need them, and the semantic emoji table is calibrated for Pedro's personal handle.
- **Curly quotes and boldface:** 0 inside tweet bodies.

### Account voice deviation, stated explicitly

`x-pedro-voice` is scoped to Pedro's personal handle. These drafts run its banlists, humanizer matchers, and density thresholds, but drop the first-person founder anchors, the signature phrases, and the emoji vocabulary, because @compozy is not a person.
