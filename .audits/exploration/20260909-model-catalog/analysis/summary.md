# Model catalog and reasoning: findings and remediation

The failures came from capability loss between discovery, merge, and persistence. Model names were available while the metadata needed to select their reasoning configuration was missing. The competitor pattern is provider-owned capability discovery, followed by exact transport negotiation.

| Confirmed cause                                                                                             | Change                                                                                                                                                   | Owning evidence                                                                               |
| ----------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| Codex generic ACP model discovery omitted each model's effort list and default                              | Use a bounded native app-server model/list probe, all pages, account environment, visibility and default metadata                                        | Native CLI response, live catalog API and Codex protocol suite                                |
| Global effort enum discarded Ultra and future values                                                        | Keep string identifiers throughout discovery, persistence, HTTP/UDS/SDK/Web; known values provide labels, advertised membership remains the runtime gate | Future-value discovery, database roundtrip and Web mapper suites                              |
| Cursor merge stripped efforts because its transport is launch arguments                                     | Retain reasoning profiles backed by transport bindings                                                                                                   | Cursor parser-to-merge regression and real Grok selection                                     |
| Invalid Cursor configuration escaped as an internal error                                                   | Classify a missing combination as a runtime validation error (400)                                                                                       | Session binding suite and isolated API rejection                                              |
| OpenCode plain listing discarded capabilities and variants; long piped output could truncate despite exit 0 | Read verbose metadata, capture complete native stdout through a bounded regular-file read, and use advertised ACP effort keys                            | Three consecutive full native refreshes plus source/parser and large-output subprocess suites |
| models.dev OpenCode Zen IDs lacked the native namespace                                                     | Qualify those source IDs as opencode/model to match ACP and avoid invalid duplicate rows                                                                 | Models.dev identity test and fresh catalog API                                                |
| Expired persisted source status suppressed first-read refresh                                               | Honor expiry while retaining no-expiry and retry-backoff behavior                                                                                        | Existing catalog service suite with a restarted service over persisted rows                   |
| Session hydration dropped ACP options                                                                       | Preserve effective and selected option values through the context                                                                                        | Session runtime hydration suite                                                               |
| Rapid changes aborted a request that might already have committed                                           | Serialize writes, coalesce the latest intent, and use the acknowledged revision                                                                          | Existing session runtime hook suite                                                           |

Primary documentation and competitor code citations are in [upstream analysis](04_analysis_upstream.md) and [competitor analysis](01_analysis_competitors.md). Live Codex 0.153.4 advertised Astra low/medium/high/xhigh/max/ultra with default medium; Luna omitted ultra. Cursor advertised Grok 4.5 low/medium/high and Grok 4.6 additionally xhigh, both default high. These are observed responses, not model-name rules in product code.

## Boundaries

- User-configured model profiles keep intentional precedence over live discovery. Provider-managed reasoning without advertised adjustable levels remains support=true with no slider; that is distinct from missing metadata.
- A transport configuration matrix is authoritative. Falling back to unrelated top-level levels could offer impossible combinations, so that proposed fallback was not applied.
- The unused deriveActiveSessionOptions helper did not explain an active selector defect and was left untouched.
- The pasted queue 400, session/presence 404 and window-manager 409 cannot establish their original causes without response bodies and lifecycle context. Read-only production logs show session removal/cancellation around the reported time. They are not evidence that every catalog failure is the same bug. The isolated walk records the current supported journey separately.
- Native discovery reflects the installed provider and current account. No static catalog or successful local test proves entitlement for unauthenticated providers.
