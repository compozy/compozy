---
title: The session list toggle leads the session header
type: fix
---

The button that shows or hides the session list now sits first in the session header, before the project name, in every session. Before, it sat among the actions on the right, and in an always-on session it disappeared once the list was hidden, leaving no way to bring the list back from the header.

The context panel now opens and closes from the context button in the message box, which works as a toggle. The header no longer has its own context button, so a regular session's header actions are **Stop** and **Changes**. An always-on session keeps **Always on** and the **…** menu.

Migration notes: no action needed; keyboard shortcuts and command palette entries for these panels are unchanged.
