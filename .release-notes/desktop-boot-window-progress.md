---
title: The desktop boot window shows real upgrade progress
type: feat
---

The CompozyOS desktop app's boot and install window is redesigned. During an upgrade it used to show one label and a gray bar, so a long data upgrade looked frozen. It now lists the steps the boot runs with their durations, a running clock, and the version you are upgrading from and to, with a **What's new** link. While session history upgrades, it shows "N of M sessions", a percentage and an estimate.

After 30 seconds of data upgrade, a note explains that you have a lot of history. After two minutes without progress, a notice offers **Open logs** and **Diagnostics** before any error appears. Failures mark the step that failed and keep **Try again**, **Open logs**, **Quit** and the diagnostics actions. While you wait, a small game runs itself; press Space or click to play.

Migration notes: no action needed.
