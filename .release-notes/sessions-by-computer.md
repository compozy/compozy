---
title: View sessions by computer
type: feature
---

List now shows a section for each computer by default. Kanban shows a band for each computer.
Use **View options → Computers → Together** to combine computers in one view.
Use the picker beside **List | Kanban** to limit a window to one computer.
Each window remembers its choices.

Set `shell.sessions.computers` to `together` or `separate` to choose the default for windows
without a layout choice.
