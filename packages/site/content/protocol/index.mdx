AGH Network is the open envelope and interaction protocol for agent conversations. These pages
describe the boundary another runtime, bridge, or test harness can implement without importing AGH
internals.

<OperatorNote>
  AGH Runtime is the reference implementation. Its current delivery path is durable commit followed
  by in-process notification. The protocol does not standardize that runtime architecture.
</OperatorNote>
