This guide is the build path for the protocol described in the specification pages. It assumes you
have read the [envelope](/protocol/envelope) and [delivery](/protocol/delivery) semantics and now
want working code.

<OperatorNote>
  The v0 wire format is what CompozyOS implements today. The Ed25519 and JCS trust profile is an
  optional v1 profile that CompozyOS does not currently implement — treat the trust verification
  walkthrough as illustrative, not as a requirement for interoperating with the runtime.
</OperatorNote>

## Before you claim conformance

Testing your own peer is not the same as claiming a conformance level. Read
[conformance](/protocol/conformance) for what each level requires, and
[implementation status](/protocol/implementation-status) for which parts of the specification
CompozyOS ships today.
