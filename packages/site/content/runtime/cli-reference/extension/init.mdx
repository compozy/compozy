## compozy extension init

Create an extension project from an embedded template

```
compozy extension init <name> [flags]
```

### Options

```
  -d, --dir string        Target directory (default: ./<name>)
  -h, --help              help for init
  -t, --template string   Template: tool-provider-ts, tool-provider-go, hook-ts, memory-backend-ts, or loop-watch-source-go (default "tool-provider-ts")
```

### Options inherited from parent commands

```
      --json            Emit JSON output
  -o, --output string   Output format: human, json, jsonl, or toon (default "human")
```

## Output Formats

Every Compozy command supports `-o, --output`:

- `human` for interactive terminal use
- `json` for scripts and other machine-readable consumers
- `jsonl` for wait or streaming commands that emit one JSON record per line
- `toon` for compact agent-readable summaries

Example:

```bash
compozy extension init <name> -o json
```
