The Compozy daemon ships a single HTTP surface under `/api`. This reference is built from
`openapi/compozy.json` at every site build, so each request and response schema below matches the
binary you are running.

<OperatorNote label="How this reference stays truthful">
  Every endpoint page is generated from `openapi/compozy.json`, which is rewritten by `make codegen`
  from the Go HTTP contract. Drift is enforced by `make codegen-check` in CI, so what you read here
  matches the daemon you build from this checkout.
</OperatorNote>

The CLI and the HTTP API operate the same daemon state. Use the
[CLI reference](/docs/cli) for end-to-end examples; use the per-tag pages here when
you need request bodies, response schemas, status codes, or SSE event shapes.

## Recommended Entry Points

### Automating session work

1. [Sessions](/docs/api/sessions) — `POST /api/sessions`, `POST /api/workspaces/:workspace_id/sessions/:session_id/prompt`, `GET /api/workspaces/:workspace_id/sessions/:session_id/events`, `GET /api/workspaces/:workspace_id/sessions/:session_id/stream`, `POST /api/workspaces/:workspace_id/sessions/:session_id/attach`, `GET /api/workspaces/:workspace_id/sessions/:session_id/recap`.
2. [Agents](/docs/api/agents) — list and inspect resolved agent definitions.
3. [Memory](/docs/api/memory) — show, write, search, and run dream checks for persistent context.

### Building operational dashboards

1. [Observe](/docs/api/observe) — task dashboard and task inbox.
2. [Memory](/docs/api/memory) — health and redacted operation history.
3. [Bridges](/docs/api/bridges) — health snapshots and SSE updates.

### Integrating runtime configuration

1. [Settings](/docs/api/settings) — read and mutate daemon settings.
2. [Vault](/docs/api/vault) — list metadata, write new refs, delete refs (no plaintext ever leaves the daemon).
3. [Workspaces](/docs/api/workspaces) and [Skills](/docs/api/skills) — register and inspect control surfaces.

### Managing extensible desired state

1. [Resources](/docs/api/resources) — read and mutate desired-state objects.
2. [Automation](/docs/api/automation) — workspace suggestions, jobs, triggers, and runs.
3. [Marketplace](/docs/api/marketplace) — discover MCP servers, extensions, skills,
   and bundles with scoped installed-state projection.
4. [Extensions](/docs/api/extensions) — install, update, remove, enable, disable,
   inspect, and read provenance/trust reports.

<OperatorNote>
  Vault read responses contain only `ref`, `namespace`, `kind`, `present`, `created_at`, and
  `updated_at`. Write requests accept `secret_value`, but no HTTP, UDS, CLI, or web response ever
  returns that value. Use UDS for local agent automation when the daemon HTTP listener is bound
  outside loopback.
</OperatorNote>
