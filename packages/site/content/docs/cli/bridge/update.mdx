## compozy bridge update

Update mutable bridge fields

```
compozy bridge update <id> [flags]
```

### Options

```
      --delivery-defaults string            JSON object or null for delivery target defaults
      --delivery-progress string            Tool progress mode: off, new, all, or verbose
      --delivery-progress-grouping string   Progress delivery grouping: accumulate or separate
      --delivery-progress-reactions         Emit reaction affordances for tool progress
      --delivery-progress-typing            Emit typing affordances for tool progress
      --display-name string                 New operator-facing bridge display name
  -h, --help                                help for update
      --include-group                       Override whether routing includes group identity
      --include-peer                        Override whether routing includes peer identity
      --include-thread                      Override whether routing includes thread identity
      --notification-suppress               Override whether notification deliveries are suppressed
      --provider-config string              JSON object or null for provider runtime config
```

### Options inherited from parent commands

```
      --json             Emit JSON output
  -o, --output string    Output format: human, json, jsonl, or toon (default "human")
      --profile string   Act as a profile for this command
```

## Output Formats

The root `-o, --output` flag accepts these values. A renderer is supported only when this command writes that result; `jsonl` is for commands that emit one JSON record per line.

| Format  | Command result                          |
| ------- | --------------------------------------- |
| `human` | Interactive terminal rendering          |
| `json`  | Machine-readable JSON rendering         |
| `jsonl` | One JSON record per line when supported |
| `toon`  | Compact agent-readable rendering        |

Example:

```bash
compozy bridge update <id> -o json
```
