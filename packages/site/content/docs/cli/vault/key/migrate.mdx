## compozy vault key migrate

Explicitly migrate the local Vault file key to the OS keyring

### Synopsis

Import the existing local vault.key, verify every encrypted record, then select os-keyring. This command can prompt for OS credential-store permission. It operates on the local CompozyOS home.

```
compozy vault key migrate [flags]
```

### Options

```
  -h, --help              help for migrate
      --remove-file-key   Remove vault.key after verified migration
```
