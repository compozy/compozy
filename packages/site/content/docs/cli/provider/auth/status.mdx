## compozy provider auth status

Show provider authentication status

### Synopsis

Show provider authentication status. For native_cli providers with an auth status command the live probe runs in the local daemon when it is reachable, so Settings shows the same verdict; otherwise it runs in this process. --local always probes in this process.

```
compozy provider auth status <provider> [flags]
```

### Options

```
  -h, --help       help for status
      --local      Run the provider status probe in this CLI process, even when the daemon is running
      --no-probe   Do not run the provider status command
      --remote     Return the daemon's probe payload through the configured client target
```

### Options inherited from parent commands

```
      --json             Emit JSON output
  -o, --output string    Output format: human, json, jsonl, or toon (default "human")
      --profile string   Act as a profile for this command
```

## Output Formats

The root `-o, --output` flag accepts these values. A renderer is supported only when this command writes that result; `jsonl` is for commands that emit one JSON record per line.

| Format  | Command result                          |
| ------- | --------------------------------------- |
| `human` | Interactive terminal rendering          |
| `json`  | Machine-readable JSON rendering         |
| `jsonl` | One JSON record per line when supported |
| `toon`  | Compact agent-readable rendering        |

Example:

```bash
compozy provider auth status <provider> -o json
```
