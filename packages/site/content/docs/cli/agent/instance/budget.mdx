## compozy agent instance budget

Manage agent instances: budget

```
compozy agent instance budget <agent-or-instance-id> [flags]
```

### Examples

```
  # Output example
  compozy agent instance budget triage --workspace my-project --tokens 100000 --usd off
```

### Options

```
      --clear              Remove both daily limits
      --global             Use the global scope
  -h, --help               help for budget
      --tokens string      Daily token cap; 'off' removes it
      --usd string         Daily estimated USD cap; 'off' removes it
      --workspace string   Workspace ID, name, or path
```
