## compozy agent duplicate

Duplicate an agent definition without exposing secrets

```
compozy agent duplicate <source> <new-name> [flags]
```

### Options

```
      --acp-option stringArray      ACP select option default (repeatable: id=value_id)
      --acp-toggle stringArray      ACP boolean option default (repeatable: id=true|false)
      --appearance-avatar string    Avatar: generated, icon or emoji (default "generated")
      --appearance-color string     Avatar color (#rrggbb) (default "#7c5cff")
      --appearance-emoji string     One emoji
      --appearance-generation int   Avatar generation (default 1)
      --appearance-icon string      Lucide icon name
      --appearance-seed string      Generated avatar seed (default: agent name)
      --category stringArray        Agent category path segment (repeatable)
      --command string              Optional provider command override
      --deny-tool stringArray       Denied tool pattern (repeatable)
      --description string          Agent purpose (up to 280 characters)
      --disable-skill stringArray   Disabled skill name (repeatable)
      --display-name string         Agent display name (up to 80 characters)
  -h, --help                        help for duplicate
      --kind string                 Agent kind: on_demand (default) or stays_on; fixed at creation
      --model string                Optional provider model

      --provider string             Provider name for sessions using this agent
      --reasoning-effort string     Optional default reasoning effort

      --speed string                Optional default runtime speed (normal or fast)
```

## Output Formats

The root `-o, --output` flag accepts these values. A renderer is supported only when this command writes that result; `jsonl` is for commands that emit one JSON record per line.

| Format  | Command result                          |
| ------- | --------------------------------------- |
| `human` | Interactive terminal rendering          |
| `json`  | Machine-readable JSON rendering         |
| `jsonl` | One JSON record per line when supported |
| `toon`  | Compact agent-readable rendering        |

Example:

```bash
compozy agent duplicate <source> <new-name> -o json
```
