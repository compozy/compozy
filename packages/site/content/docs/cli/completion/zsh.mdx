## compozy completion zsh

Generate the autocompletion script for zsh

### Synopsis

Generate the autocompletion script for the zsh shell.

If shell completion is not already enabled in your environment you will need
to enable it. You can execute the following once:

```
echo "autoload -U compinit; compinit" >> ~/.zshrc

```

To load completions in your current shell session:

```
source <(compozy completion zsh)

```

To load completions for every new session, execute once:

#### Linux:

```
compozy completion zsh > "${fpath[1]}/_compozy"

```

#### macOS:

```
compozy completion zsh > $(brew --prefix)/share/zsh/site-functions/_compozy

```

You will need to start a new shell for this setup to take effect.

```
compozy completion zsh [flags]
```

## Output Formats

This command writes its shell-completion script directly to standard output. The inherited `-o, --output` and `--json` flags do not convert that script to a command result.

| Format  | Output                        |
| ------- | ----------------------------- |
| `human` | Shell-completion script       |
| `json`  | Not a command-result renderer |
| `jsonl` | Not a command-result renderer |
| `toon`  | Not a command-result renderer |
