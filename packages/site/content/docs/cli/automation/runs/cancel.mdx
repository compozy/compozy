## compozy automation runs cancel

Cancel an orphaned automation run

### Synopsis

Cancel a run whose session is missing or stopped, preserving its history. Stop live sessions through session stop first. Admissions without a session and delegated executions are refused. Terminal runs are unchanged.

```
compozy automation runs cancel <id> [flags]
```
