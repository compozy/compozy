## compozy session reparent

Nest a top-level session under another session, or make it top-level again

### Synopsis

Adopt a session that has no parent as a child of another user session in the same workspace and profile, or make a previously adopted child top-level again. --top-level on a stopped spawned worker takes it over as a normal user session: its spawn TTL, parent auto-stop, creator wake, budget, and permission narrowing end. Subagents and continued or forked sessions keep their lineage.

```
compozy session reparent <id> [flags]
```

### Examples

```
  # Nest a top-level session under another session
  compozy session reparent sess_child --parent sess_parent

  # Make an adopted child top-level again, or take over a stopped spawned worker
  compozy session reparent sess_child --top-level
```

### Options

```
  -h, --help            help for reparent
      --parent string   Parent session ID to nest the session under
      --top-level       Make an adopted child or stopped spawned worker top-level
```
