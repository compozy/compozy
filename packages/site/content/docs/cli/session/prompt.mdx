## compozy session prompt

Send a prompt to a session

```
compozy session prompt <id> <message> [flags]
```

### Examples

```
  # Send a follow-up prompt to an active session
  compozy session prompt sess_1234 "Summarize the current changes."

  # Select the runtime snapshot for this prompt
  compozy session prompt sess_1234 "Review the patch." \
    --provider codex --model gpt-5.6-sol --reasoning-effort high --speed fast

  # Queue input while the session is busy
  compozy session prompt sess_1234 "Run the next check." --queue

  # Replace the fenced active turn with steering guidance
  compozy session prompt sess_1234 "Prefer the smaller patch." --steer --expected-turn-id turn_1234

  # Interrupt the fenced active turn before sending a replacement
  compozy session prompt sess_1234 "Use this direction instead." --interrupt --expected-turn-id turn_1234

  # Manage an already queued input
  compozy session input list sess_1234
  compozy session input cancel sess_1234 queue_entry_1234

  # Retry the same submission with its original identities
  compozy session prompt sess_1234 "Run the next check." \
    --message-id msg_1234 --idempotency-key idem_1234
```

### Options

```
      --acp-option stringArray    ACP select override as id=value (repeatable)
      --acp-toggle stringArray    ACP boolean override as id=true|false (repeatable)
      --expected-turn string      Optional strict active turn fence
  -h, --help                      help for prompt
      --idempotency-key string    Stable command idempotency key for an explicit retry
      --interrupt                 Interrupt the active turn before sending this prompt
      --message-id string         Stable authored message id for an explicit retry
      --model string              Runtime model for this prompt
      --provider string           Runtime provider for this prompt
      --queue                     Queue the prompt if the session is busy
      --reasoning-effort string   Runtime reasoning effort for this prompt (none|minimal|low|medium|high|xhigh|max)
      --speed string              Runtime speed for this prompt (normal|fast)
      --steer                     Deliver guidance into the active turn, with automatic fallback
```

## Output Formats

The root `-o, --output` flag accepts these values. A renderer is supported only when this command writes that result; `jsonl` is for commands that emit one JSON record per line.

| Format  | Command result                          |
| ------- | --------------------------------------- |
| `human` | Interactive terminal rendering          |
| `json`  | Machine-readable JSON rendering         |
| `jsonl` | One JSON record per line when supported |
| `toon`  | Compact agent-readable rendering        |

Example:

```bash
compozy session prompt <id> <message> -o json
```
