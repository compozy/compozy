## compozy session approve

Approve or reject a pending session permission request

```
compozy session approve <id> [flags]
```

### Options

```
      --decision string     Decision: allow-once, allow-always, reject-once, or reject-always
  -h, --help                help for approve
      --request-id string   Pending permission request id
      --turn-id string      Pending permission turn id
```

The root `-o, --output` flag accepts these values. A renderer is supported only when this command writes that result; `jsonl` is for commands that emit one JSON record per line.

| Format  | Command result                          |
| ------- | --------------------------------------- |

| `json`  | Machine-readable JSON rendering         |
