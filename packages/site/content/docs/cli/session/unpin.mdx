## compozy session unpin

Unpin a session so it returns to its place in the list

### Synopsis

Unpin a session. It returns with its child sessions to its project group or folder at the position it held. Unpinning a session that is not pinned changes nothing.

```
compozy session unpin <id> [flags]
```

### Examples

```
  compozy session unpin sess-123
```
