## compozy session reorder

Pin a manual session order in a folder or the workspace root

### Synopsis

Pin the listed sessions, in order, at the top of one folder (or the workspace root). Sessions already there but not listed keep their order after them. List sessions with --sort manual to see this order.

```
compozy session reorder <id>... [flags]
```

### Examples

```
  # Order two sessions at the top of the workspace root
  compozy session reorder sess_b sess_a

  # Order sessions inside a folder
  compozy session reorder sess_c sess_a --folder sfold-1234
```

### Options

```
      --folder string      Folder ID (omit for the workspace root)
  -h, --help               help for reorder
      --workspace string   Workspace ID, name, or path (defaults to the current directory)
```
