## compozy session later

Move a session and its children to Later

### Synopsis

Move a session to Later. Its active turn and runtime stop, its monitors and pending wakes are canceled, its processes and terminals are terminated, and its child sessions are parked with it. History, transcript, and worktree stay. With --return-at the session comes back into Needs you with a notification at that time.

```
compozy session later <id> [flags]
```

### Examples

```
  # Park a session with a note
  compozy session later sess-123 --reason "revisit after the billing spec"

  # Park it until a date (local midnight) or for a duration
  compozy session later sess-123 --return-at 2026-11-03
  compozy session later sess-123 --return-at 72h
```

### Options

```
  -h, --help               help for later
      --reason string      Markdown note shown on the Later card (up to 1000 characters)
      --return-at string   When the session returns to Needs you: RFC 3339 time, YYYY-MM-DD (local midnight), or a duration like 72h
```
