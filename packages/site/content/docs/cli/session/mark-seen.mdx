## compozy session mark-seen

Mark a session's Needs you as seen

### Synopsis

Mark a session's Needs you as seen. A turn that ended early, a return from Later, or a stopped session's failure leaves Needs you until it happens again. A session that still waits on a permission answer, a question, a sign-in, or a stop is refused; answer or resolve it instead. A session that does not need you is returned unchanged.

```
compozy session mark-seen <id> [flags]
```

### Examples

```
  # Clear the Needs you of a session you already looked at
  compozy session mark-seen sess-123
```
