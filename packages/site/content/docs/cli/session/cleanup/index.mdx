## compozy session cleanup

Delete archived sessions in bulk, in the background

### Synopsis

Plan a cleanup of the profile's archived sessions and, with --yes, delete them in the daemon's background. Without --yes it only previews what would go. Only archived sessions are deleted: child sessions still in the session list or in Later stay, with everything under them. Worktrees stay, as with a single delete. By default it picks threads archived more than 7 days ago in the current workspace and deletes them whole.

```
compozy session cleanup [flags]
```

### Examples

```
  # Preview what a cleanup of the current workspace would delete
  compozy session cleanup

  # Delete every thread archived more than 30 days ago, across all workspaces
  compozy session cleanup --older-than 30 --all-workspaces --yes

  # Keep main sessions; delete only their archived subagents
  compozy session cleanup --subagents --any-time --yes

  # Follow or stop the running cleanup
  compozy session cleanup status
  compozy session cleanup stop
```

### Options

```
      --all-workspaces     Clean up every project and User scope
      --any-time           Pick every archived thread, whenever it was archived
      --before string      Pick threads archived before this date: YYYY-MM-DD (local midnight) or RFC 3339
      --children           Delete archived child sessions, keeping main sessions
      --everything         Delete picked threads whole: main sessions, child sessions, and subagents (the default)
  -h, --help               help for cleanup
      --older-than int     Pick threads archived more than this many days ago (default 7)
      --session strings    Limit the cleanup to these archived main sessions, as a retry of failed threads does
      --subagents          Delete archived subagents, keeping main sessions
      --workspace string   Workspace ID, name, or path (defaults to the current workspace)
      --yes                Delete; without it the command only previews
```
