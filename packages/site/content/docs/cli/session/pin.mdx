## compozy session pin

Pin a session above the session list

### Synopsis

Pin a session above the session list. It moves on its own to the Pinned section at the top, above every project group and folder; its folder, manual position and activity order are kept. Pinning a pinned session changes nothing. Subagent sessions and always-on agents' main sessions cannot be pinned.

```
compozy session pin <id> [flags]
```

### Examples

```
  # Keep a session at the top of the list
  compozy session pin sess-123

  # List what is pinned, in pin order
  compozy session list --pinned only --sort pinned
```
