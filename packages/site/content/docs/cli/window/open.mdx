## compozy window open

Open a window as a tab or split member

```
compozy window open [flags]
```

### Options

```
      --actor-id string       Optional actor identifier
      --app string            Application route identifier
      --client string         Connected presentation client ID
      --desktop string        Destination desktop; resolved from client focus when omitted
      --floating              Deprecated: open a tab; removed in v0.8.0
  -h, --help                  help for open
      --id string             Stable window ID; generated when omitted
      --instance-key string   Optional application instance key
      --origin string         Command origin label (default "cli")
      --pathname string       Absolute application pathname
      --rect string           Deprecated: ignored floating rect; removed in v0.8.0
      --restore string        Deprecated: activate this existing window; removed in v0.8.0
      --revision uint         Expected workspace revision
      --search-json string    Route search state as a JSON object
      --stack-target string   Open a tab after this window's tab
      --tiled                 Insert beside client focus when possible
      --workspace string      Override workspace (ID, name, or path)
```

### Options inherited from parent commands

```
      --json             Emit JSON output
  -o, --output string    Output format: human, json, jsonl, or toon (default "human")
      --profile string   Act as a profile for this command
```

## Output Formats

The root `-o, --output` flag accepts these values. A renderer is supported only when this command writes that result; `jsonl` is for commands that emit one JSON record per line.

| Format  | Command result                          |
| ------- | --------------------------------------- |
| `human` | Interactive terminal rendering          |
| `json`  | Machine-readable JSON rendering         |
| `jsonl` | One JSON record per line when supported |
| `toon`  | Compact agent-readable rendering        |

Example:

```bash
compozy window open -o json
```
