## compozy workspace folder

Group workspaces into root folders

### Synopsis

Manage the profile's root workspace folders shown in All projects. Folders are one level deep and hold workspaces only. Deleting a folder returns its workspaces to the root; no workspace or session is touched.

### Options

```
  -h, --help   help for folder
```
