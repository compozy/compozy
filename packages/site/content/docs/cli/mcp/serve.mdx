## compozy mcp serve

Serve the workspace-bound Compozy Host API over MCP

```
compozy mcp serve [flags]
```

### Options

```
  -h, --help               help for serve
      --listen string      Loopback host:port for HTTP transport
      --token-env string   Environment variable containing the HTTP bearer token (default "COMPOZY_MCP_SERVE_TOKEN")
      --transport string   MCP transport: stdio or http (default "stdio")
      --workspace string   Override workspace binding (ID, name, or path)
```
