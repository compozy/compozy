## compozy task update

Update mutable task fields

```
compozy task update <id> [flags]
```

### Options

```
      --auto-enqueue-on-ready             Toggle auto-enqueue once blocking dependencies complete
      --clear-owner                       Remove the current owner
      --description string                Update the task description
      --expect string                     Replace the result contract with inline JSON or @file
  -h, --help                              help for update
      --metadata string                   Update metadata JSON
      --network string                    Network participation mode: local or live
      --network-bounds string             JSON object for live participation bounds (one object, not flag explosion)
      --network-channel string            Named channel id when strategy is named
      --network-channel-strategy string   Live channel strategy: named, run, or loop_run
      --owner-kind string                 Update the owner kind
      --owner-ref string                  Update the owner reference
      --priority string                   Update the task priority: low, medium, high, or urgent
      --result-budget string              Task result budget, for example 512KiB
      --result-overflow string            Task over-budget policy: store or reject
      --title string                      Update the task title
```

### Options inherited from parent commands

```
      --json             Emit JSON output
  -o, --output string    Output format: human, json, jsonl, or toon (default "human")
      --profile string   Act as a profile for this command
```

## Output Formats

The root `-o, --output` flag accepts these values. A renderer is supported only when this command writes that result; `jsonl` is for commands that emit one JSON record per line.

| Format  | Command result                          |
| ------- | --------------------------------------- |
| `human` | Interactive terminal rendering          |
| `json`  | Machine-readable JSON rendering         |
| `jsonl` | One JSON record per line when supported |
| `toon`  | Compact agent-readable rendering        |

Example:

```bash
compozy task update <id> -o json
```
