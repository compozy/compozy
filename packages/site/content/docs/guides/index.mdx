Runtime Guides are problem-oriented. Use them when you already know what you want CompozyOS to do and
need the shortest reliable path through the daemon, CLI, API, and web surfaces.

<OperatorNote label="How to use these guides">
  Start with the guide that matches the job in front of you. Each guide points back to the generated
  CLI and API reference when exact flags, fields, or status values matter.
</OperatorNote>

## What belongs here

Guides focus on operator outcomes:

- choose the CompozyOS surface that matches the actor and task
- recover a session or daemon state you can prove from events
- hand work between sessions through durable tasks
- route from a scenario into generated CLI/API reference only when exact syntax matters

If you are brand new to CompozyOS, start with [Quick Start](/docs/getting-started/quick-start).
If you need exact machinery, use the [CLI Reference](/docs/cli) and
[API Reference](/docs/api).
