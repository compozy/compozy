---
title: Files app
description: Browse a project's or worktree's files in their own window, without opening a session.
---

The Files app opens a project's files in a window of their own: the tree, the
[file viewer](/docs/files/file-viewer), Go to file, Search, and Find in file. Use it to read code,
search a project, look at a worktree, or follow a path an agent mentioned.

## Open it

- **Dock:** **Files** sits right after **Agents**.
- **Command palette:** **Open project files**.
- **Sessions sidebar:** open a project's menu and choose **Open files**.
- **Transcript:** a plain click on a file path in an assistant message opens the file on the
  session's root (its worktree, else the project folder) at the path's line.
- **Review panel:** **Open in Files** on a changed file opens it at its first changed line.

From a session, a new Files window opens as a tab of the session's window. Each project has one
Files window: opening it again, from any of these places, focuses the existing window and moves it
to the new root and file instead of adding another. The dock and palette open the project of the window you are focused
on, otherwise the project you used last, otherwise your first project.

## Choose the project and root

The window's head reads **Files**, then two pickers. Its tab names the open file, otherwise the
project.

- **Project** lists your projects. Archived projects are not listed.
- **Root** lists **Project root** and every ready worktree of the project, with its branch.
  Switching the root reloads the tree and keeps the same file path open.

The window remembers its root and the open file for each project.

## States

| Situation                         | What you see                                                                        |
| --------------------------------- | ----------------------------------------------------------------------------------- |
| The project was archived          | **Project archived** · "Unarchive it to browse its files again."                    |
| The project was removed           | **Project not found** · "It was removed from CompozyOS."                            |
| The selected worktree was removed | **This worktree is no longer on disk** with **Switch to project root**              |
| You have no projects yet          | **No projects yet** · "Add a project to browse its files." with a button to add one |

When you remove a project from CompozyOS, its Files window closes with it.

## Read the same files from a script

The window reads the project form of the file routes, such as
`GET /api/workspaces/{workspace_id}/files/entries` and
`GET /api/workspaces/{workspace_id}/files/content`, with `worktree_id` for a worktree root. See the
[Workspaces API reference](/docs/api/workspaces).
