---
title: Remote Computers cloud service
description: Readiness, signing keys, and the sign-in gate policy for Remote Computers.
---

The cloud service coordinates accounts and access to computers. Agent sessions run on the computers that host them. Their prompts, files, and traffic stay on those computers and the routes between them.

## Public endpoints

| Endpoint                                        | Response                                                                          |
| ----------------------------------------------- | --------------------------------------------------------------------------------- |
| `GET /healthz`                                  | `200` with `{"status":"ok"}` when the replica can serve requests                  |
| `GET /v1/jwks` and `GET /.well-known/jwks.json` | The same public Ed25519 key set, including verification keys kept during rotation |
| `GET /v1/gate-policy`                           | A compact JWS (`application/jose`) with `mode`, `until`, `message`, and `iat`     |

The policy decides whether the sign-in gate is enforced or has a temporary grace period. Its `until` is UTC in RFC 3339 format for grace and `null` for enforcement. `iat` is a Unix timestamp in seconds. Verify the signature against the cloud JWKS before applying grace, and check that its deadline is still in the future.

A replica that is draining or unavailable can return `503 cloud_unavailable`. Account-scoped writes can return `429 rate_limited`. Both responses include `Retry-After` in seconds.
