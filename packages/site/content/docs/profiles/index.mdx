---
title: Profiles
description: Separate work and operator context on one CompozyOS installation, then select the profile each command or session uses.
---

A profile is an operator-owned partition of CompozyOS work. Every installation starts with the permanent
`default` profile. Existing work belongs to `default`, and creating another profile does not move it.

Profiles are global identities. A workspace remembers which profile to use, but the profile itself is not
owned by that workspace. Sessions bind the resolved profile when they are created, so a later selection
change does not rewrite an existing session.

Start with the generated [`compozy profile`](/docs/cli/profile) reference or list the current catalog:

```bash
compozy profile list
compozy profile current
```

Agents running inside CompozyOS can inspect the same truth with `compozy__profile_list` and
`compozy__profile_current`. Resolve each live descriptor before calling it. Profile mutations remain on
the local CLI, HTTP, UDS, desktop, and command-palette surfaces.
