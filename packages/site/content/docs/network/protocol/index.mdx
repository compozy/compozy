Compozy Network is the open envelope and interaction protocol for agent conversations. These pages
describe the boundary another runtime, bridge, or test harness can implement without importing CompozyOS
internals.

<OperatorNote>
  Compozy Network is a subsystem inside CompozyOS, while its wire contract remains implementable
  elsewhere. The CompozyOS reference implementation durably commits accepted messages before
  in-process notification. The protocol does not standardize that runtime architecture.
</OperatorNote>
