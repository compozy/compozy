# @compozy/brand

The Compozy brand manual (v1.2.0, November 2026) as a React 19 + TanStack Start site. Every route
prerenders to static HTML. Colours, fonts and gradients come from `@compozy/ui` tokens
(`packages/ui/src/tokens.css`); the manual reads them by name and never redefines them.

## Scripts

Run from `packages/brand`, or through Turborepo from the repo root
(`bunx turbo run build test typecheck lint --filter=@compozy/brand`).

| Script      | What it does                                                                                |
| ----------- | ------------------------------------------------------------------------------------------- |
| `dev`       | Dev server on http://localhost:4620                                                         |
| `build`     | Prerenders every route to `.output/public`, then `scripts/assert-build-output.ts` checks it |
| `preview`   | Serves the build on http://localhost:4620 (unknown URLs answer 404 with the not-found page) |
| `typecheck` | Native `tsc --noEmit`                                                                       |
| `lint`      | `oxfmt --check` and `oxlint --deny-warnings`                                                |
| `test`      | Vitest: chapter registry, status badge, public asset budget and srcset policy               |

The build check fails when a chapter in `src/manual/chapters.ts` has no prerendered page, a page
misses its status badge or a section anchor, or `404.html` is missing.

## Layout

- `src/routes/` — one file per chapter slug (`index.tsx` is chapter 01 Foundations), plus `404.tsx`
  and the `__root.tsx` document shell. `routeTree.gen.ts` is generated by the router plugin.
- `src/manual/chapters.ts` — the chapter registry: number, title, summary, `approved`/`proposal`
  status, cover visual and section index. Approving a chapter means flipping its `status` here.
- `src/manual/parts/` — manual shell: layout, nav and section index, cover, section, status tag,
  prev/next cards, do/don't, generated image, not-found.
- `src/manual/art/` — the visual registry and `<Visual>`. Atmosphere visuals render from
  `public/brand/visuals`; product shots and diagrams render a marked slot until they are captured
  from the real `web/` UI.
- `src/manual/foundations/` — chapter 01 sections and their copy (`data.ts`).

## Assets

`public/brand/` holds web-size files only: `svg/`, `png/`, Atmosphere `visuals/*-1280.jpg` and
`visuals/*.jpg` (2560 px), and the generated images a ported chapter shows (`img/`). A test keeps
`public/` at or under 15 MB with no file over 2 MB.

Hi-res masters, `visuals/hi`, kit and digital exports, and raw generations stay out of git in
`~/Dev/compozy/_rebranding` — see its `README.md` for the index. The hi srcset tier is listed in
`HI_TIER` (`src/manual/art/visuals.ts`) only once its file is published under
`public/brand/visuals/hi/`.
