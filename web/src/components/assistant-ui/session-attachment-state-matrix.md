# Session attachment state matrix

| Surface          | Default                                     | Hover/focus                                    | Disabled                                                             | Error or blocked                                                                       | Reduced motion                                 |
| ---------------- | ------------------------------------------- | ---------------------------------------------- | -------------------------------------------------------------------- | -------------------------------------------------------------------------------------- | ---------------------------------------------- |
| Attach button    | Paperclip action with an action title.      | Shared button hover and focus tokens.          | No pointer events; reduced opacity.                                  | —                                                                                      | No component animation.                        |
| Drop root        | Overlay hidden.                             | Dragging shows the inert, accent-dim overlay.  | Drag state is cleared; overlay stays hidden.                         | Unsupported input is reported by its tile.                                             | No entry animation.                            |
| Attachment tile  | Ready preview with remove action.           | Remove/retry actions use shared button states. | Composer state owns availability.                                    | Rejected input shows the supported-format reason; transient save failure offers retry. | No entry animation.                            |
| Capability gate  | Hidden for supported or unknown capability. | Remove action uses shared button states.       | —                                                                    | Lists every blocked image/PDF kind and removes only those files.                       | No entry animation.                            |
| Queue controls   | Queue and Interrupt accept durable refs.    | Shared control states.                         | Steer stays disabled for attachment-bearing drafts or queued inputs. | Daemon admission remains authoritative while capability is unknown.                    | No entry animation.                            |
| Attachment rails | Content-aligned horizontal rail.            | Edge fades follow scroll position.             | —                                                                    | —                                                                                      | Scrolling and fades honor `useAttachmentRail`. |
