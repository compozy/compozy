# Skill Authoring Terms

Lookup only when a term needs clarification.

## Predictability

A dependable outcome and contract. Repeating an identical process is necessary only when that order protects correctness.

## Model-Invoked

A skill the harness can discover and select from its metadata. Invocation controls vary by harness.

## User-Invoked

A skill explicitly selected by the user. Preserve metadata required by the target harness; do not assume removing a description disables automatic invocation.

## Description

Concise discovery metadata naming the task and useful exclusions.

## Context Pointer

A path plus the condition and section needed to resolve a task-specific question.

## Context Load

Material actually loaded into the model context, including metadata and reference content. Measure it across representative tasks.

## Cognitive Load

Attention the user must spend selecting tools, correcting scope, or supplying decisions.

## Router Skill

An entry point selecting the relevant procedure without loading every available branch.

## Granularity

How finely skills and references are divided. Split when there is an independent trigger or a useful reusable contract.

## Information Hierarchy

Common task contract first; branch-specific detail on demand.

## Steps

Actions whose order is necessary for dependencies, mutations, authorization, or correctness.

## Reference

Knowledge consulted to answer a relevant question.

## External Reference

A canonical document outside the skill package, linked with its applicable scope.

## Progressive Disclosure

Loading material when it is needed; moving a mandatory full read into another file alone saves no context.

## Co-location

Keep a contract and the caveats needed to apply it together.

## Sprawl

Material whose loading/maintenance cost exceeds its task value. Prune or narrow its trigger.

## Branch

A distinct task path; only its applicable instructions bind.

## Leading Word

An optional familiar term that clarifies a concrete instruction. Rhetorical intensity is not a substitute for a precise scope.

## Completion Criterion

An observable result and the applicable evidence that ends the task.

## Legwork

Investigation needed to resolve a real uncertainty; stop when that uncertainty is settled.

## Post-Completion Steps

Follow-on work that needs its own task justification; it does not automatically extend the current scope.

## Premature Completion

Claiming the requested result before its relevant contract/evidence is satisfied.

## Negation

A prohibition is appropriate for a concrete tripwire. Prefer clear targets over long lists of hypothetical mistakes.

## Single Source of Truth

The authoritative owner of a rule, with links from its consumers.

## Duplication

The same rule maintained or executed in several places without independent need.

## Relevance

Whether the material changes a decision in the task being performed.

## Sediment

Historical guidance retained after its assumptions or owning process changed.

## No-Op

An instruction that adds no useful behavior. Delete it; do not automatically escalate it to a stronger adjective.
